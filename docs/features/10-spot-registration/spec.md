# 스팟 제보 등록 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
사용자가 새 **스팟(`Spot`)** 을 제보하여 콘텐츠를 자생적으로 확장한다. 제보는 즉시 `USER_REPORTED` 상태로 지도에 노출되고, 운영자 사후 검수와 3명 이상 GPS 인증에 의한 자동 승격으로 신뢰도가 올라간다. (prd §13·§18·§25)

## 진입점 / 사용자
- **진입**: 하단 내비의 **제보 탭**(3번째, `/report`). (prd §9 — 2026-09-03 [#120](https://github.com/MapStargram/SPOTCHU/pull/120)으로 지도/탐색의 + 플로팅 버튼에서 변경)
- **사용자**: `USER` 이상. `GUEST`는 제보 탭 진입 시 **소프트 게이트**로 로그인 요구 → 로그인 후 폼 복귀. (prd §8·§36)
- `TRUSTED_USER`는 제보 즉시 노출 신뢰도 가산(효과 상세는 `rules.md` TODO). (prd §36)

## 화면 상태
- **비로그인 게이트**: `GUEST`가 제보 탭 진입 → 로그인 유도.
- **폼 초기**: 필수/선택 필드 폼 + 지도 피커.
- **촬영자 위치 지정**: 지도 핀으로 `shooterLat`/`shooterLng` 지정 → 역지오코딩으로 주소·도시 프리필.
- **촬영 대상 지점 지정(선택)**: 지도에서 '촬영 대상 지점' 탭 → `subjectLat`/`subjectLng` 저장 + `bearing` 자동 계산·화살표 미리보기.
- **중복 안내**: 근접 기존 스팟 감지 시 안내 배너(제보는 계속 가능).
- **유효성 오류**: 필수 누락·안전 태그 미체크 시 인라인 오류.
- **안전 차단**: 철도 선로 등 고위험 유형 선택 시 등록 차단 안내.
- **제출 중 / 완료**: 제출 성공 시 `USER_REPORTED`로 생성·지도 즉시 노출 + 사후 검수 예정 고지.

## 구성 요소
- **제보 탭**: 하단 내비 3번째 탭. 제보 진입점.
- **지도 피커**: 촬영자 위치 핀(드래그/탭) + '촬영 대상 지점' 탭 → `bearing` 미리보기 화살표.
- **필수 입력(MVP)**: 이름, 카테고리(`Category`), 촬영자 좌표(`shooterLat`/`shooterLng`), 도시(`City`), 대표 사진, 촬영 대상 텍스트(`subject`). (prd §13)
- **선택 입력**: 카메라 방향(`bearing`, 대상 지점 탭 자동), 접근 방법, 촬영 팁, 추천 시간대/계절, 추천 렌즈·줌, 난이도, 혼잡도, 주의사항, 관련 작품/회차(`SpotWork`: `episode`/`sceneNote`), 원본 장면(외부 공식 출처 링크). (prd §13·§24)
- **대표 사진 업로더**: 업로드 사진의 EXIF 위치는 서버 저장 전 제거. (prd §23)
- **안전 태그 체크박스(필수)**: 사유지 / 철도 / 차도 / 영업장 + 촬영 매너 고지. (prd §25)
- **중복 안내 배너**: 근접 기존 스팟 목록 + "그래도 제보" 액션(운영자 병합 대상).
- **제출 버튼**: 서버 검증 후 생성.

## 인터랙션 흐름
1. 제보 탭 진입 → `GUEST`면 소프트 게이트 → 로그인 후 폼.
2. 지도에서 **촬영자 위치** 핀 지정 → 역지오코딩으로 주소·도시 프리필.
3. (선택) **촬영 대상 지점** 탭 → `subjectLat`/`subjectLng` 저장 + `bearing` 자동 계산.
4. 이름·카테고리·대표 사진·촬영 대상 텍스트 등 필수 입력.
5. 안전 태그 체크(필수). 철도 선로 등 고위험 유형 선택 시 등록 차단 안내.
6. (선택) 접근 방법·촬영 팁·작품 연결·원본 장면 링크 등 입력.
7. 근접 기존 스팟이 있으면 중복 가능성 안내(제보 계속 가능).
8. 제출 → 서버 필수 검증 → `verificationStatus = USER_REPORTED` 생성 → 지도 즉시 노출 → 사후 검수 예정 고지. (prd §18)

## 엣지 케이스
- **비로그인 제보 시도**: 소프트 게이트로 로그인 요구, 성공 후 폼 복귀. (prd §8)
- **위치 권한 거부**: 지도 수동 핀 지정으로 폴백. (prd §00 IA)
- **고위험 유형(철도 선로 등)**: 등록 차단, 사유 안내. (prd §25)
- **안전 태그 미체크**: 제출 불가(필수). (prd §25)
- **필수 필드 누락**(예: 대표 사진 없음): 인라인 검증 오류로 제출 차단.
- **대표 사진 EXIF 위치**: 서버 저장 전 제거. (prd §23)
- **원본 장면**: 원본 스틸 호스팅 금지 → 외부 공식 출처 링크만 저장. (prd §24)
- **중복 스팟 제보**: 근접 기존 스팟 안내 후에도 제보 가능, 병합은 운영자 판단. (prd §18)
- **좌표 오입력**: 재확인 유도(구체 유효성 규칙은 `rules.md` TODO).
- **네트워크/이미지 업로드 실패**: 재시도, 입력값 유지.

## 인수 조건 (Given/When/Then)
- **Given** 로그인한 `USER`가, **When** 제보 탭에서 필수 항목(이름·카테고리·촬영자 좌표·도시·대표 사진·촬영 대상)을 채우고 안전 태그를 체크한 뒤 제출, **Then** 스팟이 `verificationStatus = USER_REPORTED`로 생성되어 즉시 지도에 노출된다.
- **Given** 제보 폼에서, **When** 안전 태그 중 '철도(선로)' 등 고위험 유형을 선택하고 제출을 시도, **Then** 등록이 차단되고 사유 안내가 표시된다.
- **Given** 비로그인(`GUEST`) 사용자, **When** 제보 탭으로 제보를 시도, **Then** 소프트 게이트로 로그인을 요구하고 로그인 후 폼으로 복귀한다.
- **Given** 지도에서 '촬영 대상 지점'을 탭, **When** 촬영자 위치와 대상 지점이 정해짐, **Then** `bearing`(방위각)이 자동 계산되어 화살표로 미리보기된다.
- **Given** 해당 `USER_REPORTED` 스팟에 서로 다른 사용자 3명 이상이 GPS 방문 인증, **When** 3번째 인증이 누적, **Then** `verificationStatus`가 `USER_VERIFIED`로 자동 승격된다.

## 관련 API / 데이터
- 엔티티: `Spot`(`shooterLat`/`shooterLng`, `subject`/`subjectLat`/`subjectLng`, `bearing`, `verificationStatus`, `checkinRadiusM`, `City`, `Category`), `SpotWork`(`episode`, `sceneNote`), `Category`, `City`. (prd §35, glossary)
- 서버 액션: 제보 생성(필수 필드 서버 검증 · `verificationStatus = USER_REPORTED` 강제 · 안전 태그 저장 · 고위험 차단 · 역지오코딩 · 집계 초기화). 상세 시그니처·권한은 `docs/api-surface.md`(예정), 필드 정의는 `docs/data-model.md`(예정). (prd §13·§37)
- 사후 검수/병합: `11-admin-moderation`. 승격 규칙: `07-gps-checkin` + glossary 검증 상태 승격.
