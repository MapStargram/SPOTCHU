# 탐색(지도⇄피드) — 개발·도메인 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 불변식
- 지도 핀/스팟 좌표는 **항상 촬영자 위치**(`shooterLat`/`shooterLng`). 촬영 대상(피사체) 좌표를 핀으로 쓰지 않는다(PRD §12, 용어집).
- 카메라 방향(`bearing`)은 탐색 지도에서 표시하지 않는다. 방향 화살표는 **스팟 상세**에서만(PRD §12).
- 검증 상태는 색만으로 전달하지 않는다. **색 + 아이콘/라벨 병기**(PRD §30).
- 핀 인코딩 규약: 색 = 검증 상태, 아이콘 = 카테고리, 숫자 = 클러스터(PRD §12). 이 매핑을 임의로 바꾸지 않는다.
- 열람은 항상 비로그인 허용, 액션(제보 등)만 게이트한다(PRD §8·§36).
- 지도 데이터는 **뷰포트 기반 + 디바운스**로만 로드한다. 도시 전체 스팟 일괄 로드 금지(PRD §30).
- 탐색 기본 뷰는 **지도**(진입 시 현재 위치 기준으로 중심 이동, 권한 거부·타 도시 브라우징 시 도시 중심), 피드는 토글. (현재 위치 우선 진입으로 변경 — 발견을 현장 맥락에 붙임.)
- 피드는 스팟 발견 수단이다 — 팔로우·댓글 등 SNS 기능을 여기서 만들지 않는다(PRD §4·§5).

## Do / Don't
- **Do**: 뷰포트(경계 상자) 쿼리로 스팟 로드, 이동/줌에 디바운스 적용, 밀집 구간 클러스터링.
- **Do**: 검증 상태를 색+아이콘/라벨로 함께 표기.
- **Do**: 지도 로드·세션당 호출을 지표화([`../14-metrics-analytics/spec.md`](../14-metrics-analytics/spec.md)).
- **Do**: 비로그인 열람 허용, 제보 버튼에서만 소프트 게이트.
- **Don't**: 촬영 대상 좌표를 핀 위치로 사용.
- **Don't**: 색만으로 검증 상태 구분.
- **Don't**: 도시 전체/광역 스팟을 한 번에 로드.
- **Don't**: 열람 자체를 로그인으로 막기.
- **Don't**: 정해지지 않은 지도 비용 임계·핀 색상·디바운스 값을 임의로 발명(→ TODO).

## 데이터·권한 규칙
- **열람**: `GUEST` 허용(피드·지도·미니 카드).
- **제보(+ 버튼)**: `USER` 이상. 비로그인 시도 시 소프트 게이트([`../01-auth-onboarding/spec.md`](../01-auth-onboarding/spec.md)).
- **스팟 조회 스코프**: 기본 = 현재 선택 도시. '전체에서 검색' 토글은 검색·필터로 위임(PRD §19).
- **'지금 내 주변'**: 현재 위치 반경 조회(PostGIS). 위치 권한이 있어야 하며, 이 위치 사용은 **조회 목적에 한정**한다(방문 인증의 위치 사용과 별개, [`../07-gps-checkin/spec.md`](../07-gps-checkin/spec.md)).
- **위치정보**: 실시간 위치는 조회 시점에만 사용, 좌표 이력을 저장하지 않는다(PRD §23).

## 정책 연동
- **비용 관리**(PRD §12·§30·§31): 뷰포트 로드·디바운스·클러스터로 지도 호출 최소화, 호출/세션 지표화, 정적 지도·타일 캐싱 폴백 검토.
- **검색·필터·정렬**: [`../05-search-filter/spec.md`](../05-search-filter/spec.md)로 위임(필터 항목·정렬 기본값 포함).
- **스팟 제보**: [`../10-spot-registration/spec.md`](../10-spot-registration/spec.md), 소프트 게이트: [`../01-auth-onboarding/spec.md`](../01-auth-onboarding/spec.md).
- **검증 상태 정의·승격 규칙**: 용어집 및 [`../11-admin-moderation/spec.md`](../11-admin-moderation/spec.md).
- **접근성**: 색+아이콘/라벨 병기, 시맨틱 마크업·대체 텍스트(PRD §29·§30).
