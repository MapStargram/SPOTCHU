# 탐색(지도⇄피드) — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
선택 도시 안에서 스팟(`Spot`)을 발견하는 단일 화면. **사진 피드(기본) ⇄ 지도**를 한 화면에서 토글로 전환하고, 검색창·필터로 좁혀 들어간다. 피드는 인스타식 SNS가 아니라 **스팟을 발견하기 위한 수단**이다(PRD §4). 지도는 "장소"가 아니라 **촬영자가 서는 위치**(`shooterLat`/`shooterLng`)를 핀으로 보여준다(PRD §12).

## 진입점 / 사용자
- **진입점**: 하단 내비 `탐색` 탭(PRD §9, [`../00-information-architecture/spec.md`](../00-information-architecture/spec.md)). 홈·검색 결과·컬렉션 지도 등에서의 진입은 각 화면 문서에서 다룬다.
- **사용자 / 권한**:
  - `GUEST`(비로그인): 피드·지도 **열람 자유**(PRD §8·§36).
  - `USER` 이상: 열람 + 스팟 제보(+ 버튼). 액션은 **소프트 게이트**로 로그인 유도([`../01-auth-onboarding/spec.md`](../01-auth-onboarding/spec.md)).
- **전제 상태**: 전역 "현재 선택 도시"가 정해져 있어야 한다(기본: 최근 선택 → 위치 기반 추천 → 서울/도쿄 유도, [`../00-information-architecture/spec.md`](../00-information-architecture/spec.md)).

## 화면 상태
| 상태 | 설명 |
|---|---|
| 로딩 | 피드/지도 초기 로드 중 스켈레톤 표시. |
| 피드 뷰(기본) | 선택 도시 스팟의 사진 그리드. 상단에 검색창·필터·지도 토글. |
| 지도 뷰 | 토글 후 Google Maps 지도. 뷰포트 내 스팟 핀/클러스터 표시. |
| 빈 상태 | 선택 도시에 노출 스팟 없음 → 다른 도시 선택/제보 유도(PRD §00 IA). |
| 위치 권한 거부 | '지금 내 주변' 및 현재 위치 표시 비활성 → 도시 중심 폴백. |
| 지도 로드 실패 | 약전계/오프라인 등으로 지도 미로드 → 재시도, 정적 지도 폴백 검토(임계 TODO). |
| 에러 | 데이터 로드 실패 → 재시도 안내. |

## 구성 요소
- **검색창**: 탭 시 검색·필터 화면으로 진입([`../05-search-filter/spec.md`](../05-search-filter/spec.md)). 검색 대상·범위(선택 도시 기본 + "전체에서 검색")는 PRD §19.
- **필터 진입 / 필터 바**: 카테고리 · 검증 상태 · 작품 · 시간대 · **'지금 내 주변'**(PRD §19). 세부 정의는 05 문서로 위임.
- **뷰 토글**: 지도 ⇄ 피드 전환. 기본값 = **지도**(진입 시 현재 위치로 중심 이동, 거부/타 도시 시 도시 중심).
- **사진 피드 그리드**: 스팟 대표 사진 카드. 카드 탭 → 스팟 상세([`../04-spot-detail/spec.md`](../04-spot-detail/spec.md)).
- **지도(Google Maps JS API)**:
  - **핀 인코딩**(PRD §12): 색 = 검증 상태(`verificationStatus`), 아이콘 = 카테고리(`Category`). 색만으로 구분하지 않고 아이콘/라벨 병기(PRD §30).
  - **클러스터**: 밀집 시 숫자 배지로 묶음.
  - **현재 위치 표시**: 위치 권한 허용 시.
  - **뷰포트 로드 컨트롤**: 이동/줌 시 뷰포트 기준으로 스팟을 로드(디바운스). 자동 재로드 vs "이 지역 재검색" 버튼 방식은 TODO.
- **스팟 미니 카드**: 핀 탭 시 대표 사진·이름·검증 상태·카테고리 요약. 탭 → 스팟 상세.
- ~~**+ 플로팅 버튼**~~: 제거됨(2026-09-03, [#120](https://github.com/MapStargram/SPOTCHU/pull/120)). 스팟 제보 진입은 하단 내비 **제보 탭**으로 이동([`../10-spot-registration/spec.md`](../10-spot-registration/spec.md)).
- **도시 컨텍스트 표시**: 현재 선택 도시명(변경은 홈/도시 선택에서).

## 인터랙션 흐름
1. **진입**: 탐색 탭 → 선택 도시 사진 피드 기본 로드.
2. **뷰 전환**: 토글 → 지도 뷰, 현재 뷰포트의 스팟만 로드(디바운스).
3. **지도 탐색**: 이동/줌 → 뷰포트 기반 재로드(디바운스). 밀집 구간은 클러스터로 표시.
4. **핀 탭**: 미니 카드 노출 → 탭 시 스팟 상세로 이동.
5. **클러스터 탭**: 줌인(또는 하위 스팟 펼침)으로 개별 핀 노출.
6. **검색**: 검색창 탭 → 검색·필터 화면([`../05-search-filter/spec.md`](../05-search-filter/spec.md)).
7. **'지금 내 주변'**: 필터 선택 → 위치 권한 요청 → 허용 시 현재 위치 반경 스팟 조회(PostGIS 반경 쿼리, PRD §12·§19).
8. **제보**: + 버튼 → (비로그인이면 소프트 게이트) → 스팟 제보 등록.

## 엣지 케이스
- **위치 권한 거부**: '지금 내 주변'·현재 위치 표시 비활성, 도시 중심으로 폴백 안내(PRD §00 IA).
- **선택 도시 콘텐츠 없음**: 빈 상태 + 다른 도시/제보 유도.
- **지도 로드 실패(약전계/오프라인)**: 재시도, 정적 지도 폴백 검토(발동 임계 TODO, PRD §41.4).
- **스팟 과밀 뷰포트**: 클러스터로 묶어 렌더 부하·지도 호출 최소화(PRD §30).
- **비로그인 + 버튼 탭**: 열람은 유지, 액션만 소프트 게이트.
- **좌표 오인 방지**: 핀은 **촬영자 위치**만 나타낸다. 촬영 대상(피사체) 좌표를 핀으로 쓰지 않는다(PRD §12, 용어집).
- **넓은 줌/전체에서 검색**: 뷰포트가 매우 넓을 때의 로드 상한·클러스터 임계는 TODO.

## 인수 조건 (Given/When/Then)
- **Given** 탐색 탭 진입, **When** 기본 로드, **Then** 지도가 먼저 보이고(위치 권한 허용 시 현재 위치 중심) 상단에 피드 토글이 있다.
- **Given** 지도 뷰, **When** 지도를 이동/줌, **Then** 전체 도시가 아니라 **뷰포트 내 스팟만** 디바운스 후 로드된다.
- **Given** 지도 뷰에서 스팟이 밀집, **When** 렌더, **Then** 숫자 클러스터로 묶여 표시된다.
- **Given** 지도 핀, **When** 표시, **Then** 색은 검증 상태를, 아이콘은 카테고리를 나타내며 색만으로 구분하지 않는다(아이콘/라벨 병기).
- **Given** 비로그인 사용자, **When** 피드·지도를 열람, **Then** 막힘 없이 열람하되 + 제보 버튼 탭 시 로그인 소프트 게이트가 뜬다.
- **Given** '지금 내 주변' 필터, **When** 위치 권한 허용, **Then** 현재 위치 반경 내 스팟이 표시된다.
- **Given** 위치 권한 거부, **When** '지금 내 주변' 시도, **Then** 도시 중심 폴백으로 안내한다.

## 관련 API / 데이터
- **엔티티**: `Spot`(`shooterLat`, `shooterLng`, `verificationStatus`, 카테고리, 대표 사진), `Category`, `City`, `Post`(피드 사진). 필드 정의: [`../../data-model.md`](../../data-model.md).
- **쿼리**: 뷰포트(경계 상자) 기반 스팟 조회, '지금 내 주변' PostGIS 반경 쿼리(PRD §12·§19).
- **API 시그니처·권한**: [`../../api-surface.md`](../../api-surface.md).
- **연계 화면**: 검색·필터([`../05-search-filter/spec.md`](../05-search-filter/spec.md)), 스팟 상세([`../04-spot-detail/spec.md`](../04-spot-detail/spec.md)), 스팟 제보([`../10-spot-registration/spec.md`](../10-spot-registration/spec.md)), 지표 이벤트([`../14-metrics-analytics/spec.md`](../14-metrics-analytics/spec.md)).

## 구현 노트 — §12 브랜드 지도·마커·길찾기 (반영됨)
- **브랜드 지도**: `@vis.gl/react-google-maps` + AdvancedMarker + Cloud **Map ID**(`NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID`, 미설정 시 데모). **브랜드 스타일·기본 POI 숨김(최소 컨텍스트 유지)은 Google Cloud Console의 Map ID 스타일에서 설정**(계정 액션) — 코드는 env만 읽는다.
- **마커 썸네일**: 마커 = 대표 사진 원형 썸네일 + 검증상태 링색 + 카테고리 이모지 배지(색+아이콘/라벨 병기). 이미지 없으면 이모지 폴백. `loading="lazy"` + 클러스터로 비용 관리.
- **길찾기**: 스팟 상세에서 Google Maps 딥링크(`/maps/dir/?api=1&destination=<shooterLat,Lng>&travelmode=walking`). 인앱 라우팅 미구현, origin 생략(현재 위치 자동), 무단 위치 프롬프트 없음.
- **뷰포트 서버 로드·디바운스**(반영됨): 지도가 자체적으로 뷰포트 내 스팟만 로드한다 — `idle`(이동/줌 정착) → 디바운스 400ms → `GET /api/spots/bounds`(도시 스코프 bbox, 상한 500) → 마커 id-diff. 도시 전체 일괄 로드 폐지(rules §불변식). 데이터 계층: `lib/bounds.ts`(순수 bbox), `lib/data.getSpotsInBounds`(목업 필터 ↔ DB Float 범위 쿼리). 결정값: [`./rules.md`](./rules.md) §결정됨.
- **후속(미반영)**: 클러스터(상한 초과·밀집), bbox 공간 인덱스, 인앱 직선거리 표시(위치 프롬프트 UX 검토 필요), 피드 리스트 페이지네이션.
