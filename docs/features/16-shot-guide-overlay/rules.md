# 촬영 가이드 오버레이 (구도 맞추기) — 개발·도메인 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) §28-9 · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)
> **포스트-MVP**. 착수 전 이 문서의 TODO/미결정을 먼저 해소한다.

## 불변식
- **오버레이 소스는 (A) 스팟 대표 실촬영 사진(CC·자가호스팅) 또는 (B) 구도 라인 드로잉 뿐이다. 작품 원본 스틸은 절대 소스가 아니며 직접 호스팅하지 않는다** (prd §24). 이 불변식은 저작권의 핵심이며 어떤 경우에도 완화하지 않는다.
- 오버레이 소스가 CC 사진이면 **저작자·라이선스·출처를 병기**한다 (prd §24, `imageCredit`).
- 오버레이는 **참고용**이다 — 촬영을 강제하거나 프레임 일치를 검사하지 않는다(자동 채점은 prd §28-3의 별개 기능).
- 카메라 권한은 **이 기능 사용 시에만** 요청·사용한다. 라이브 프리뷰 프레임은 **저장하지 않는다** — 사용자가 셔터로 캡처해 업로드(09)할 때만 서버로 전송된다 (prd §23 최소 수집 원칙과 정합).
- 업로드되는 사진은 09의 규칙을 따른다 — **EXIF 위치 제거**(prd §6·§23).
- `bearing`은 촬영자 위치에서 촬영 대상을 향한 방위각(0–360°)이며 힌트 표시에만 쓴다. 좌표 불변식(prd §12)을 바꾸지 않는다.

## Do / Don't
- **Do** 오버레이 소스가 없으면 진입 버튼을 숨긴다(빈 오버레이·깨진 이미지 노출 금지).
- **Do** 불투명도 슬라이더로 겹침 정도를 사용자가 조절하게 한다(기본값은 은은하게, TODO).
- **Do** 카메라 권한 거부·미지원 시 대표 사진 정적 참고 이미지로 **폴백**하고 상세 열람은 막지 않는다.
- **Do** `getUserMedia`는 보안 컨텍스트(HTTPS)에서만 동작함을 전제한다(PWA 전제, prd §29).
- **Do** 후면 카메라(`facingMode: environment`)를 우선한다.
- **Don't** 작품 원본 스틸·외부 지오태그 원본 이미지를 오버레이 소스로 쓰거나 재호스팅하지 않는다 (prd §24).
- **Don't** 라이브 카메라 프레임을 서버로 자동 전송·저장하지 않는다(캡처+업로드는 사용자 명시 액션).
- **Don't** 구도 "일치도"를 점수화하지 않는다(포스트-MVP §28-3 범위, 혼동 금지).
- **Don't** 오버레이를 왜곡해 실제 구도를 오도하지 않는다(종횡비 유지·레터박스).

## 데이터·권한 규칙
- **권한** (prd §36): `GUEST`는 프리뷰 열람 가능하나 **촬영 결과 저장·업로드는 소프트 게이트**. `USER` 이상만 업로드.
- **오버레이 소스 선택 우선순위**: 스팟에 구도 라인 자산이 있으면 그것을, 없으면 대표 사진을 사용(구체 우선순위는 TODO).
- **성능**: 저사양 기기에서 프리뷰 저하 시 오버레이 정지 이미지 유지, 크래시 금지. 프레임 캡처는 Canvas 로컬 처리.
- **접근성** (prd §29·§30): 불투명도 컨트롤 키보드 조작·라벨 제공. 오버레이는 색 단독 정보 전달 금지. 카메라 목적 고지 텍스트 제공.

## 정책 연동
- 저작권(prd §24): 오버레이 원본 스틸 미사용, 소스 제한, CC 출처 병기. → [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/)
- 개인정보(prd §23): 카메라는 사용 시에만, 라이브 프레임 미저장, 업로드 EXIF 제거. → [`../09-community-feed-upload/`](../09-community-feed-upload/)
- 업로드 파이프라인: 캡처 → 업로드(EXIF 제거·Cloudinary). → [`../09-community-feed-upload/`](../09-community-feed-upload/)
- AR 준비(prd §42.2): 마커=POI=(미래)AR=오버레이가 동일 데이터원(좌표·방위각·표시타입)을 쓰도록 표현/데이터 분리.
