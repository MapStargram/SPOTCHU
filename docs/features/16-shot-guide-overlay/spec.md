# 촬영 가이드 오버레이 (구도 맞추기) — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) §28-9 · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)
> **포스트-MVP**. MVP 비목표(prd §5·§27 "구도 유사도 AI")를 침범하지 않는다 — 본 기능은 **자동 채점 없는 수동 구도 가이드**다.

## 목적
현장에서 카메라 프리뷰 위에 **스팟 대표 사진(실촬영) 또는 구도 라인**을 반투명 오버레이로 띄워, 사용자가 "같은 구도"로 촬영하도록 돕는다. 지도가 "어디"를, 스팟 상세가 "어디 서서 어느 방향"(prd §12 `bearing`)을 알려준다면, 이 화면은 그 자리에서 **"프레임을 어떻게 맞추는가"** 를 눈으로 겹쳐 보여준다. 애니 성지에서 원작과 같은 사진을 남기는 경험(舞台めぐり 벤치마크)을 저작권 안전 범위(prd §24)에서 재현한다. 구도 유사도 자동 채점(prd §28-3)의 **전(前)단계 수동 가이드**이며, 데이터·표현 분리는 AR 준비(prd §42.2)와 공유한다.

## 진입점 / 사용자
- **진입점**: 스팟 상세([`../04-spot-detail/spec.md`](../04-spot-detail/spec.md))의 **'구도 맞춰 찍기' 버튼**. 별도 탭 아님. (선택) GPS 방문 인증 성공 후 사진 추가 유도 지점([`../07-gps-checkin/spec.md`](../07-gps-checkin/spec.md))에서도 진입.
- **사용자 역할** (prd §36):
  - `GUEST`: 오버레이 프리뷰 자체는 카메라 권한만 있으면 열람 가능하나, **촬영 결과 저장·업로드는 소프트 게이트**(로그인).
  - `USER`/`TRUSTED_USER`: 오버레이로 촬영 → 업로드(09) 연동.
  - `MODERATOR`/`ADMIN`: 추가 권한 없음.
- **전제**: 카메라 권한 허용. 오버레이 소스(대표 사진 또는 구도 라인 자산)가 스팟에 존재.

## 화면 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| 초기 | 스팟 상세에서 '구도 맞춰 찍기' 노출 | 오버레이 가능 여부(소스 존재)에 따라 버튼 활성/숨김 |
| 권한 요청 | 카메라 권한 미획득 | 목적 고지 + 권한 요청. 거부 시 목적 재고지·재시도 안내 |
| 프리뷰 | 카메라 스트림 + 오버레이 | 라이브 프리뷰 위 반투명 오버레이 + **불투명도 슬라이더** |
| 소스 없음 | 대표 사진·구도 라인 모두 없음 | 진입 불가(버튼 숨김) 또는 일반 카메라로 폴백 안내 |
| 촬영 완료 | 셔터 → 프레임 캡처 | 미리보기 → 업로드(09) 또는 다시 찍기 |
| 권한 거부 | 카메라 접근 거부 | 오버레이 불가 안내 + 설정 유도. 상세 열람은 유지 |
| 미지원 브라우저 | `getUserMedia` 미지원 | 기능 비활성 + 대표 사진 정적 참고 이미지로 폴백 |

## 구성 요소
| 항목 | 코드 식별자 | 구분 | 표시 규칙 |
|---|---|---|---|
| 카메라 프리뷰 | (`getUserMedia` 라이브 스트림) | 필수 | 후면 카메라 우선(`facingMode: environment`) |
| 구도 오버레이 | `Spot`(대표 사진) 또는 구도 라인 자산 | 필수(둘 중 하나) | 프리뷰 위 반투명 레이어. **원본 작품 스틸 미사용** (prd §24) |
| 불투명도 슬라이더 | (클라 상태) | 필수 | 오버레이 투명도 0–100% 조절 |
| 방위각 힌트 | `bearing` | 선택 | 촬영 방향(prd §12). 없으면 미표시 |
| 시간대·계절 힌트 | (선택 필드) | 선택 | 추천 시간대(야경/일몰 등, prd §13) 텍스트 |
| 셔터 | (클라) | 선택 | 프레임 캡처 → 업로드(09) 진입. 로그인 필요 |
| 소스 출처 표기 | `imageCredit` | 조건부 | 오버레이가 CC 대표 사진이면 저작자·라이선스·출처 병기 (prd §24) |

## 인터랙션 흐름
```
스팟 상세 → [구도 맞춰 찍기]
  → (소스 없으면 버튼 숨김/폴백)
  → 카메라 권한 요청·획득
  → 라이브 프리뷰 + 반투명 오버레이(대표 사진 또는 구도 라인)
  → 불투명도 슬라이더로 겹침 조절, (있으면) 방위각·시간대 힌트 참고
  → [셔터] → (GUEST면 소프트 게이트) → 프레임 캡처 → 미리보기
    → 업로드(09, EXIF 위치 제거) 또는 다시 찍기
```
- 오버레이는 **참고용**이며 촬영을 강제하지 않는다(자유 촬영 가능).
- 캡처 프레임은 업로드 전 로컬 미리보기이며, 업로드 시에만 서버로 전송된다.

## 엣지 케이스
- **오버레이 소스 없음**: 대표 사진·구도 라인 모두 없는 스팟은 진입 버튼을 숨긴다(빈 오버레이 노출 금지).
- **카메라 권한 거부**: 오버레이 불가 안내 + 대표 사진을 정적 참고 이미지로 제시. 스팟 상세 열람은 유지.
- **`getUserMedia` 미지원·비보안 컨텍스트(HTTP)**: 기능 비활성, 정적 폴백. (PWA는 HTTPS 전제, prd §29)
- **전면/후면 카메라 전환 실패**: 사용 가능한 스트림으로 폴백, 방향 안내만.
- **`bearing` 없음**: 방위각 힌트 미표시, 오버레이·불투명도는 정상.
- **저사양 기기 성능 저하**: 프리뷰 프레임레이트 저하 시 오버레이 정지 이미지 유지(크래시 금지).
- **가로/세로 방향 불일치**: 오버레이 종횡비를 프리뷰에 맞춰 레터박스 처리(왜곡 금지).

## 인수 조건 (Given/When/Then)
- **Given** 대표 사진이 있는 스팟, **When** '구도 맞춰 찍기'로 진입, **Then** 카메라 프리뷰 위에 **대표 사진이 반투명 오버레이**로 겹쳐 표시되고 불투명도를 조절할 수 있다.
- **Given** 어떤 스팟이든, **When** 오버레이를 표시, **Then** **작품 원본 스틸은 절대 오버레이 소스로 쓰이지 않는다**(대표 실촬영 사진 또는 구도 라인만) (prd §24).
- **Given** 오버레이 소스가 CC 대표 사진, **When** 프리뷰를 표시, **Then** 저작자·라이선스·출처가 병기된다 (prd §24).
- **Given** 카메라 권한이 거부됨, **When** 진입을 시도, **Then** 목적을 재고지하고 정적 참고 이미지로 폴백하며 스팟 상세 열람은 막지 않는다.
- **Given** 비로그인(`GUEST`), **When** 셔터로 촬영 결과를 저장/업로드, **Then** 소프트 게이트로 로그인 후 원래 업로드가 이어진다.
- **Given** `bearing`이 없는 스팟, **When** 오버레이를 표시, **Then** 방위각 힌트는 표시되지 않고 나머지는 정상 동작한다.
