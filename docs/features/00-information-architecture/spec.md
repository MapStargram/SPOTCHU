# 정보구조 · 하단 내비게이션 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
앱 전역의 탐색 구조와 하단 내비게이션을 정의한다. 첫 진입은 **도시 탐색 중심**, 지도와 피드 사이를 쉽게 전환하는 것이 핵심.

## 하단 내비게이션 (4탭)
| 탭 | 역할 | 진입 화면 |
|---|---|---|
| 홈 | 발견의 시작점(큐레이션) | 도시 선택 + 도시별 추천 컬렉션·에디토리얼·인기 스팟·시즌 테마 |
| 탐색 | 검색·지도 | 선택 도시 기준 **사진 피드**(기본) ⇄ 지도 토글, 검색창·필터 |
| 컬렉션 | 저장·계획 | 내 컬렉션 목록(+기본함 "저장됨") |
| 프로필 | 나의 기록 | 방문 기록·배지·내 사진·설정 |

- **스팟 제보**: 탭 아님 → 지도/탐색의 **+ 플로팅 버튼**.
- **방문 인증**: 스팟 상세 내 버튼.
- **탐색 기본 표시** = 사진 피드, 상단 토글로 지도.

## 전역 상태
- 현재 선택 도시(기본: 최근 선택 → 없으면 위치 기반 추천 → 서울/도쿄 중 선택 유도).
- 로그인 상태(GUEST/USER/…): 액션 시 소프트 게이트.

## 대표 사용자 흐름
```
도시 선택 → 추천 컬렉션/피드 → 피드⇄지도 전환 → 스팟 상세 → 저장 → (현장) 방문 인증 → (선택) 업로드
```

## 엣지 케이스
- 위치 권한 거부: 도시 수동 선택으로 폴백.
- 선택 도시에 콘텐츠 없음: 빈 상태 + 다른 도시/제보 유도.
- 비로그인이 컬렉션/프로필 탭 진입: 열람 가능한 부분만 표시 + 액션 시 로그인.

## 인수 조건 (Given/When/Then)
- **Given** 앱 첫 진입, **When** 도시 미선택, **Then** 도시 선택 UI가 우선 노출된다.
- **Given** 탐색 탭 진입, **When** 기본 로드, **Then** 사진 피드가 먼저 보이고 상단에 지도 토글이 있다.
- **Given** 비로그인 사용자, **When** 하단 탭을 이동, **Then** 홈·탐색·스팟 상세를 막힘 없이 열람한다.
