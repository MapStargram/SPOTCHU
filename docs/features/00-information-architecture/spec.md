# 정보구조 · 하단 내비게이션 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
앱 전역의 탐색 구조와 하단 내비게이션을 정의한다. 첫 진입은 **전체 지역 둘러보기(DISCOVER) 피드 중심**이며, 도시 선택은 강제 게이트가 아니라 선택 사항이다. 지도와 피드 사이를 쉽게 전환하는 것이 핵심.

> 결정(2026-09-01, [#84](https://github.com/MapStargram/SPOTCHU/issues/84)): 다도시 확장(서울·도쿄→오사카·교토·후쿠오카·부산 등)에 맞춰 첫 진입을 "도시 선택 강제 게이트"에서 "전체 지역 둘러보기 우선 + 도시 선택은 선택('도시별로' → `/home/[city]`)"으로 확정. 이 문서는 그 실제 구현을 원천으로 반영한다.

## 하단 내비게이션 (5탭)
| 탭 | 역할 | 진입 화면 |
|---|---|---|
| 홈 | 발견의 시작점 | 전체 지역 둘러보기 피드(기본, `/home`) + 도시별 화면(`/home/[city]`, '도시별로'로 진입) |
| 탐색 | 검색·지도 | 선택 도시 기준 **사진 피드**(기본) ⇄ 지도 토글, 검색창·필터 |
| 제보 | 새 스팟 등록 | 제보 플로우(`/report`, [`../10-spot-registration/spec.md`](../10-spot-registration/spec.md)). `GUEST`는 소프트 게이트 |
| 컬렉션 | 저장·계획 | 내 컬렉션 목록(+기본함 "저장됨") |
| 프로필 | 나의 기록 | 방문 기록·배지·내 사진·설정 |

> 개정(2026-09-03, [#120](https://github.com/MapStargram/SPOTCHU/pull/120)): 4탭 + 제보 FAB → **5탭(제보를 3번째 탭으로 승격)**. 탐색 화면의 제보 + 플로팅 버튼은 제거(prd §9).
>
> **참고 — 이 결정은 유사 앱 관행과는 반대 방향이다.** 결정 전 비교 조사에서 AllTrails(5탭: Explore·Saved·Navigate·Activity·Profile)와 Airbnb(Explore·Wishlists·Trips·Profile) 모두 **기여·제보 성격의 기능을 하단 탭에 두지 않았고**, 알림도 탭이 아니라 프로필/설정 안에 뒀다. AllTrails가 5번째 슬롯에 쓴 건 정보 탭이 아니라 "지금 활동을 시작·기록한다"는 **액션 탭(Navigate)** 이었다. 그럼에도 제보를 탭으로 올린 것은 SPOTCHU 초기 단계에서 **스팟 DB 확장 속도**를 발견성보다 우선한 제품 판단이다 — 콘텐츠가 충분히 쌓인 뒤에는 이 슬롯을 재검토할 여지가 있다(체크인 액션 탭으로의 교체 등).

- **방문 인증**: 스팟 상세 내 버튼.
- **탐색 기본 표시** = 사진 피드, 상단 토글로 지도.

## 전역 상태
- 현재 선택 도시(기본: 최근 선택 → 없으면 위치 기반 추천 → 서울/도쿄 중 선택 유도).
- 로그인 상태(GUEST/USER/…): 액션 시 소프트 게이트.

## 대표 사용자 흐름
```
전체 지역 둘러보기(또는 '도시별로' 선택) → 피드⇄지도 전환 → 스팟 상세 → 저장 → (현장) 방문 인증 → (선택) 업로드
```

## 엣지 케이스
- 위치 권한 거부: 도시 수동 선택으로 폴백.
- 선택 도시에 콘텐츠 없음: 빈 상태 + 다른 도시/제보 유도.
- 비로그인이 컬렉션/프로필 탭 진입: 열람 가능한 부분만 표시 + 액션 시 로그인.

## 인수 조건 (Given/When/Then)
- **Given** 앱 첫 진입, **When** 도시 미선택, **Then** 전체 지역 둘러보기 피드가 기본 노출되고 도시 선택은 '도시별로'(→ `/city`/`/home/[city]`)로 선택 진입한다. (#84)
- **Given** 탐색 탭 진입, **When** 기본 로드, **Then** 사진 피드가 먼저 보이고 상단에 지도 토글이 있다.
- **Given** 비로그인 사용자, **When** 하단 탭을 이동, **Then** 홈·탐색·스팟 상세를 막힘 없이 열람한다.
