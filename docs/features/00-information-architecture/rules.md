# 정보구조 · 내비게이션 — 규칙 (rules)

## 불변식 (Invariants)
- 하단 내비는 **정확히 5탭**(홈·탐색·제보·컬렉션·프로필). 탭 추가·삭제·순서 변경은 PRD 개정 없이는 금지(prd §9).
- 탐색 탭 기본 표시는 **사진 피드**. 지도는 토글로 접근.
- 방문 인증은 탭이 아니다(스팟 상세 내 버튼).

## Do / Don't
- ✅ 도시 컨텍스트를 전역 상태로 유지하고 모든 탐색/검색에 반영한다.
- ✅ 지도⇄피드 전환은 화면 이동 없이 같은 화면 내 토글로 처리한다.
- ❌ 첫 진입을 지도-only로 열지 않는다(도시·큐레이션 우선).
- ❌ 비로그인 사용자의 열람을 막지 않는다(액션만 게이트).

## 데이터·권한 규칙
- GUEST: 홈/탐색/스팟상세/작품상세/컬렉션(공개) 열람. 저장·인증·업로드·좋아요 불가.
- 도시 목록·큐레이션은 서버에서 도시별로 제공.

## 정책 연동
- 소프트 게이트 정책은 [`../01-auth-onboarding/`](../01-auth-onboarding/) 를 따른다.
