# 홈(도시 선택·큐레이션)·작품 상세 — 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 불변식 (Invariants)
- 홈의 역할은 **큐레이션 진입**이다. 첫 진입을 지도-only로 열지 않는다 (IA rules).
- 큐레이션은 **선택 도시 컨텍스트**를 따른다. 도시 없이 큐레이션을 먼저 노출하지 않는다.
- MVP 도시는 **서울 + 도쿄뿐**. 도시 추가는 PRD 개정 없이는 금지 (PRD §26).
- 운영자 추천 컬렉션은 사용자 컬렉션과 **동일 엔티티 `Collection`** 이며 `isOfficial = true` 플래그로만 구분한다. 별도 엔티티를 만들지 않는다 (PRD §15).
- 성지순례 진행률은 **사용자별 방문 인증(`CheckIn`) 기준**이며, 스팟당 최초 1회만 unique로 집계한다 (PRD §17).
- 작품 상세의 좌표·스팟 표기는 항상 **촬영자 위치(`shooterLat/Lng`)** 기준 (glossary).

## Do / Don't
- ✅ 도시 미선택 시 도시 선택 UI를 큐레이션보다 우선 노출한다.
- ✅ 검증 상태(`verificationStatus`)는 **색 + 아이콘/라벨** 병기로 표기한다 (PRD §30).
- ✅ 큐레이션 섹션 중 일부가 비면 해당 섹션만 숨기고 나머지를 노출한다.
- ✅ 작품 원본 장면은 텍스트(`sceneNote`) + 외부 공식 출처 링크로만 안내한다.
- ✅ 비로그인 열람을 허용하고, 저장·인증 등 **액션 시점에만** 소프트 게이트한다.
- ❌ 작품 원본 스틸 이미지를 서비스에 호스팅/재호스팅하지 않는다 (PRD §24).
- ❌ 인기도를 별도 수동 입력값으로 두지 않는다 — 저장·인증·좋아요 파생으로 계산한다 (PRD §16).
- ❌ "시즌 테마" 큐레이션을 "시즌 배지"(MVP 제외, PRD §27)로 확장하지 않는다.
- ❌ 홈에서 비로그인의 열람을 막지 않는다 (IA rules).

## 데이터·권한 규칙
- **열람 권한**: `GUEST`는 홈·큐레이션·작품 상세·공개 컬렉션을 열람 (PRD §36, IA rules).
- **액션 권한**: 저장·방문 인증은 `USER` 이상. 비로그인 시도 시 소프트 게이트.
- **큐레이션 제공**: 도시별 큐레이션(운영자 추천 컬렉션·인기 스팟·에디토리얼·시즌 테마)은 **서버에서 도시별로** 제공 (IA rules).
- **성지순례 진행률**: 서버가 (작품 연결 스팟 총수, 사용자 unique 인증 스팟 수)를 계산해 반환. 삭제/숨김 스팟은 분모·분자에서 제외.
- **작품 대표 이미지**: 운영자 관리 값(`Work` 대표 이미지)만 사용. 원본 스틸과 구분.
