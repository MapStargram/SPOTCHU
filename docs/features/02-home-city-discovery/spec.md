# 홈(도시 선택·큐레이션)·작품 상세 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
홈은 **발견의 시작점(큐레이션)** 이다. 사용자가 도시를 고르면 그 도시의 추천 콘텐츠(운영자 추천 컬렉션·에디토리얼·인기 스팟·시즌 테마)를 한눈에 훑고 탐색/저장/현장 방문 루프로 진입하게 만든다 (PRD §7·§9). 지도-only가 아니라 **도시·큐레이션 우선**으로 첫 화면을 연다.

이 문서는 두 화면을 함께 다룬다.
- **홈**: 도시 선택 + 도시별 큐레이션 진입 화면.
- **작품(Work) 상세(경량)**: 특정 작품에 연결된 스팟 리스트와 사용자별 **성지순례 진행률**을 보여주는 화면 (PRD §14).

## 진입점 / 사용자
- **진입점**
  - 홈: 하단 내비 `홈` 탭. 앱 첫 진입 기본 화면 (PRD §9, [`../00-information-architecture/spec.md`](../00-information-architecture/spec.md)).
  - 작품 상세: 스팟 상세의 연결 작품, 검색 결과(작품명), 홈 큐레이션 내 작품 카드(노출 시)에서 진입. (홈 큐레이션에 작품 섹션을 두는지 여부는 미정 → rules TODO)
- **사용자 / 권한** (PRD §36, IA rules)
  - `GUEST`(비로그인): 홈·큐레이션·작품 상세를 **막힘 없이 열람**. 저장·인증 등 액션 시도 시에만 소프트 게이트.
  - `USER` 이상: 열람 + 컬렉션 저장, 방문 인증으로 성지순례 진행률 반영.

## 화면 상태
### 홈
| 상태 | 조건 | 표시 |
|---|---|---|
| 로딩 | 큐레이션 데이터 요청 중 | 스켈레톤(도시 헤더 + 섹션 플레이스홀더) |
| 도시 미선택 | 최근 선택 없음·위치 추천 실패 | **도시 선택 UI 우선 노출**(서울/도쿄 선택 유도) (IA 인수조건) |
| 정상 | 도시 선택됨 + 큐레이션 존재 | 도시 헤더 + 큐레이션 섹션들 |
| 부분 빈 상태 | 일부 섹션만 콘텐츠 없음 | 해당 섹션 숨김, 나머지 정상 표시 |
| 전체 빈 상태 | 선택 도시에 큐레이션 콘텐츠 없음 | 빈 상태 안내 + 다른 도시 전환/제보 유도 (IA 엣지) |

### 작품 상세
| 상태 | 조건 | 표시 |
|---|---|---|
| 로딩 | 작품·스팟 리스트 요청 중 | 스켈레톤 |
| 정상 | 작품 + 연결 스팟 존재 | 작품 헤더 + 스팟 리스트 + 진행률 |
| 진행률(GUEST) | 비로그인 | 진행률 자리에 로그인 유도(총 스팟 수만 표시) |
| 스팟 없음 | 연결 스팟 0개 | 빈 상태 + 제보 유도 |

## 구성 요소
### 홈
- **도시 헤더 / 도시 선택 시트**
  - 현재 선택 도시(`City`)를 표시하고 탭하면 도시 선택 시트를 연다.
  - MVP 도시: **서울 + 도쿄**(동시 출시, PRD §26). 시트는 이 2개 도시를 나열한다.
  - 선택 도시는 전역 상태로 유지되어 탐색/검색에 반영된다 (IA rules).
- **큐레이션 섹션(도시별, 서버 제공)** — IA spec의 홈 구성(추천 컬렉션·에디토리얼·인기 스팟·시즌 테마)에 대응:
  1. **운영자 추천 컬렉션**: `Collection` 중 `isOfficial = true` 를 캐러셀로 노출. 사용자 컬렉션과 **동일 엔티티**이며 플래그로만 구분한다 (PRD §15).
  2. **에디토리얼**: 도시별 편집 콘텐츠 블록. (엔티티/데이터 소스 미정 → rules TODO)
  3. **인기 스팟**: 도시 기준 인기 상위 `Spot` 리스트. 인기도 = 저장수 + 인증수 + 연결 게시물 좋아요 합산 **파생 지표** (PRD §16).
  4. **시즌 테마**: 시즌 큐레이션 블록(예: 야경/일출/계절). (구성·데이터 소스 미정 → rules TODO. 단 "시즌 배지"는 MVP 제외 PRD §27 — 테마 큐레이션과 혼동 금지)
- 각 카드에는 검증 상태를 **색+아이콘/라벨** 병기로 표기(색만으로 정보 전달 금지, PRD §30).

### 작품 상세
- **작품 헤더**: `Work`(제목, 유형(애니/영화/드라마/…), 대표 이미지(운영자 관리), 설명) (PRD §14). 대표 이미지는 운영자 관리 이미지이며 **작품 원본 스틸이 아니다**.
- **연결 스팟 리스트**: `SpotWork`(다대다)로 연결된 `Spot`을, 회차·장면 메모(`episode`, `sceneNote`)와 함께 나열. 각 항목에서 스팟 상세로 진입.
- **성지순례 진행률**: 해당 작품 연결 스팟 중 사용자가 **방문 인증(`CheckIn`)** 한 스팟 비율. 스팟당 최초 1회만 unique 집계(PRD §17). 사용자별로 계산.
- **원본 장면 안내**: 작품 원본 스틸은 서비스가 직접 호스팅하지 않으므로 텍스트(`sceneNote`) + 외부 공식 출처 링크로만 안내한다 (PRD §24, 정책은 [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/) 참조).

## 인터랙션 흐름
```
[홈]
앱 진입 → (선택 도시 있음?) ── 예 → 도시별 큐레이션 로드 → 섹션 탐색
                          └ 아니오 → 도시 선택 시트 우선 노출 → 도시 선택 → 큐레이션 로드
큐레이션 카드 탭 → 컬렉션 상세 / 스팟 상세 / 작품 상세 로 이동
도시 헤더 탭 → 도시 선택 시트 → 다른 도시 선택 → 전역 도시 변경 → 큐레이션 재로드

[작품 상세]
작품 진입 → 작품 헤더 + 연결 스팟 리스트 + 진행률 표시
스팟 항목 탭 → 스팟 상세로 이동
(로그인 사용자) 현장 방문 인증 완료 시 → 진행률 갱신
(GUEST) 진행률 영역 탭 → 소프트 게이트(로그인 유도)
```
- 도시 선택 시 위치 기반 자동 추천을 시도하되, 실패/거부 시 수동 선택으로 폴백한다 (IA spec 전역 상태·엣지).
- 큐레이션 → 저장 등 액션은 [`../06-collections-planning/`](../06-collections-planning/) 저장 시트로 연결, 비로그인은 소프트 게이트 ([`../01-auth-onboarding/`](../01-auth-onboarding/)).

## 엣지 케이스
- **위치 권한 거부**: 위치 기반 도시 추천 불가 → 도시 선택 시트로 폴백(수동 선택). (IA 엣지)
- **선택 도시 콘텐츠 없음**: 빈 상태 안내 + 다른 도시 전환/제보 유도([`../10-spot-registration/`](../10-spot-registration/)).
- **큐레이션 일부 섹션 비어 있음**: 빈 섹션은 숨기고 나머지를 정상 노출(전체 빈 상태와 구분).
- **네트워크/약전계로 큐레이션 로드 실패**: 재시도 안내, 캐시된 마지막 도시/섹션이 있으면 우선 표시.
- **작품 연결 스팟 0개**: 리스트 빈 상태 + 제보 유도, 진행률은 0/0 처리(분모 0 표기 주의).
- **비로그인 진행률 조회**: 개인 진행률 계산 불가 → 총 스팟 수만 표시하고 로그인 유도.
- **삭제/숨김 처리된 스팟이 작품에 연결**: 리스트에서 제외하고 진행률 분모에서도 제외.

## 인수 조건 (Given/When/Then)
- **Given** 앱 첫 진입이고 선택 도시가 없을 때, **When** 홈이 로드되면, **Then** 도시 선택 UI가 큐레이션보다 우선 노출된다.
- **Given** 서울이 선택된 상태, **When** 홈 큐레이션이 로드되면, **Then** 서울의 운영자 추천 컬렉션(`isOfficial = true`)·인기 스팟이 도시 기준으로 표시된다.
- **Given** 비로그인(`GUEST`) 사용자, **When** 홈·작품 상세를 열람하면, **Then** 막힘 없이 열람되며 저장·인증 등 액션 시도 시에만 로그인 게이트가 뜬다.
- **Given** 어떤 작품 상세를 로그인 사용자가 열람, **When** 연결 스팟 N개 중 M개를 방문 인증했을 때, **Then** 성지순례 진행률이 M/N(스팟당 최초 1회 기준)으로 표시된다.
- **Given** 도시 선택 시트가 열림, **When** 도쿄를 선택하면, **Then** 전역 선택 도시가 도쿄로 바뀌고 홈 큐레이션이 도쿄 기준으로 재로드된다.

## 관련 API / 데이터
- 엔티티: `City`, `Collection`(`isOfficial`, `visibility`, cover), `CollectionItem`(`order`), `Spot`(+ `verificationStatus`, 인기 파생 지표), `Work`(제목·유형·대표이미지·설명), `SpotWork`(`episode`, `sceneNote`), `CheckIn`(진행률 산정). 필드 정의: [`../../data-model.md`](../../data-model.md).
- 서버는 **도시별 큐레이션**을 제공한다(운영자 추천 컬렉션·인기 스팟·에디토리얼·시즌 테마). 전체 API 시그니처·권한: [`../../api-surface.md`](../../api-surface.md).
- 인기도 파생: 저장수 + 인증수 + 연결 게시물 좋아요 합산 (PRD §16).
- 저작권: 작품 원본 스틸 미호스팅 — [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/) (PRD §24).
