# 컬렉션 · 저장 · 순서 편집 — 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 불변식 (Invariants)
- **스팟 ↔ 컬렉션은 다대다.** 한 스팟은 여러 컬렉션에 중복 저장될 수 있다. (PRD §15)
- **기본함 `저장됨`은 사용자당 1개 자동 생성**되며 삭제·이름변경 불가. 원탭 저장의 기본 목적지다.
- **컬렉션 기본 공개범위 = `PRIVATE`.** 공개 옵션은 `LINK`(링크 아는 사람 열람) 뿐이다(전체 공개 없음). (PRD §15)
- **운영자 추천 컬렉션은 별도 엔티티가 아니라 동일 `Collection` + `isOfficial` 플래그**다.
- **컬렉션 지도 핀 = 촬영자 위치(`shooterLat`/`shooterLng`)** 만 사용. 촬영 대상 위치를 핀으로 찍지 않는다. (PRD §12, glossary)
- **방문 진행률/완주는 컬렉션 내 방문 인증 완료 스팟 기준.** 스팟당 방문 완료는 최초 1회만 unique 카운트(재방문 중복 없음). (PRD §17)
- **`CollectionItem.day`는 스키마에 존재하되 MVP에서 사용·노출하지 않는다**(nullable, 후속 날짜 일정 확장용). (PRD §15·§28)

## Do / Don't
- ✅ 저장·생성·편집은 **소프트 게이트**(액션 시에만 로그인 요구). 열람은 막지 않는다.
- ✅ 원탭 저장은 **기본함 `저장됨`에 즉시 저장**하고, 컬렉션 지정은 저장 바텀시트에서 선택으로 처리한다.
- ✅ 순서 편집은 **드래그 앤 드롭**으로 하고 `order`를 서버에 반영한다.
- ✅ 지도 핀은 **색=검증 상태, 아이콘=카테고리, 숫자=클러스터** 인코딩을 일관 적용하고, 검증 상태는 색+아이콘/라벨을 병기한다. (PRD §12·§30)
- ❌ **날짜별 일정 UI를 MVP에 넣지 않는다**(`day` 노출 금지). (PRD §27)
- ❌ **작품 원본 스틸을 커버로 호스팅하지 않는다** — 커버는 스팟 실촬영/사용자 사진. (PRD §24)
- ❌ **`isOfficial` 컬렉션을 일반 사용자가 편집·삭제·재정렬하게 하지 않는다.**
- ❌ 같은 컬렉션에 같은 스팟을 **중복 추가하지 않는다**(다른 컬렉션 간 중복은 허용).

## 데이터·권한 규칙
- `GUEST`: 공개(`LINK`) 컬렉션·`isOfficial` 컬렉션 **열람만**. 저장·생성·편집 불가(시도 시 소프트 게이트).
- `USER`: 자신의 컬렉션 CRUD, 스팟 저장/해제, 순서 편집, 공개범위 변경. **타인 소유 컬렉션은 편집 불가.**
- 타 사용자 컬렉션: `PRIVATE`는 비열람, `LINK`는 링크 소지 시 **읽기 전용** 열람.
- `isOfficial` 컬렉션 생성·편집: `MODERATOR`/`ADMIN` 전용. (PRD §21·§36)
- 공개범위 값은 `PRIVATE`/`LINK` 두 가지로 고정.
- 진행률 계산은 서버 파생 지표(컬렉션 스팟 × 소유자 `CheckIn` 완료)로 제공한다.

## 구현 현황
- **컬렉션 상세 지도(반영됨)**: 가짜 배경·하드코딩 좌표 폐지 → 실제 Google Maps(`components/collections/CollectionMap`). 핀=촬영자 위치(shooterLat/Lng), 번호=순서, 점선=동선 경로, 전체 스팟 경계 맞춤(fitBounds), 클릭 시 상세. 키 없으면 폴백 배경.
- **리스트/캐러셀 실사진 썸네일(반영됨)**: 그라디언트 위에 대표 사진(`imageUrl`) 표시.
- **스팟 빼기(반영됨)**: 내 컬렉션(`isOwn` && !`isOfficial`)에서 `removeSpotAction`로 제거(서버 소유권 검증) + 낙관적 갱신.
- **순서 편집(반영됨)**: 내 컬렉션 상세에서 "순서 편집" 모드 → 항목 위/아래 이동 → "완료" 시 `reorderCollectionAction`으로 `CollectionItem.order` 트랜잭션 반영(소유권 검증). 지도 동선·번호도 순서 반영. 드래그앤드롭 인터랙션은 후속 폴리시(모바일 터치는 라이브러리 없이 불안정 → 현재는 위/아래).
