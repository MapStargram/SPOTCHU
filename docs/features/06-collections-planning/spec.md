# 컬렉션 · 저장 · 순서 편집 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
사용자가 발견한 스팟을 **저장**하고, **컬렉션**(여행 계획 단위)으로 정리·순서 편집·지도 확인하며, 방문 진행률로 완주까지 추적하는 경험을 정의한다. 저장은 원탭으로 시작되고, 계획은 컬렉션 탭에서 이어진다. (PRD §8·§15·§26)

핵심 루프의 "컬렉션 저장 → 순서 정리 → 현장 방문 → 진행률·완주"를 담당한다. 컬렉션 예시: `도쿄 3박4일`, `슬램덩크 성지순례`, `서울 야경 명소`.

## 진입점 / 사용자
- **저장 진입점**: 스팟 카드(피드·목록) 및 스팟 상세의 **원탭 저장** 버튼.
- **컬렉션 진입점**: 하단 내비 **컬렉션 탭**(내 컬렉션 목록 + 기본함 `저장됨`). (PRD §9, [`../00-information-architecture/spec.md`](../00-information-architecture/spec.md))
- **LINK 공개 진입점**: 공개 링크 URL(비로그인 포함 링크 소지자 열람).
- **사용자·권한** (PRD §36):
  - `GUEST`: 공개(`LINK`) 컬렉션·운영자 추천(`isOfficial`) 컬렉션 **열람만**. 저장·생성·편집 시 소프트 게이트.
  - `USER`: 자신의 컬렉션 생성·편집·삭제, 저장/해제, 순서 편집, 공개범위 변경.
  - `MODERATOR`/`ADMIN`: `isOfficial` 컬렉션 관리(본 스펙의 편집 UI 재사용, 상세는 [`../11-admin-moderation/spec.md`](../11-admin-moderation/spec.md)).

## 화면 상태
1. **저장 바텀시트** — 원탭 저장 시 열림. 기본함 `저장됨`에 자동 저장된 상태로, 추가로 **컬렉션 선택**(다중 가능)과 **새 컬렉션 만들기**를 제공.
2. **컬렉션 목록** — 기본함 `저장됨` + 사용자 생성 컬렉션 + 운영자 추천(`isOfficial`) 컬렉션. 각 카드: 커버·제목·스팟 수·진행률 요약·공개범위 표시.
   - **빈 상태**: 컬렉션 없음 → `저장됨` 안내 + 스팟 저장/탐색 유도.
3. **컬렉션 상세** — 스팟 항목 리스트(순서대로) + **방문 진행률 바/완주 표시** + `지도로 보기` + (소유자) 순서 편집·공개범위·편집.
   - **빈 상태**: 항목 0개 → 스팟 추가 유도.
4. **순서 편집 모드** — 드래그 앤 드롭으로 항목 재정렬, 항목 제거.
5. **컬렉션 지도 뷰** — 컬렉션에 저장된 스팟 핀을 한 번에 표시(핀 = 촬영자 위치).
6. **새 컬렉션 만들기** — 제목(필수)·설명·공개범위(기본 `PRIVATE`)·커버 입력.
7. **LINK 공개 뷰** — 링크 소지 비소유자가 보는 읽기 전용 컬렉션 상세(편집·저장 컨트롤 숨김).

## 구성 요소
- **원탭 저장 버튼**: 스팟 카드/상세. 저장됨 상태 토글 표시(저장/해제).
- **저장 바텀시트**: 기본함 자동 저장 배지 + 컬렉션 체크 목록 + `+ 새 컬렉션 만들기`.
- **컬렉션 카드**: 커버, 제목, 스팟 수, 진행률(`n/총`), 공개범위 아이콘, `isOfficial` 배지.
- **진행률 바 / 완주 배지**: 컬렉션 내 **방문 인증 완료 스팟 수 / 전체 스팟 수** 기준. 전부 완료 시 완주 표시. (인증 기준은 [`../07-gps-checkin/spec.md`](../07-gps-checkin/spec.md))
- **스팟 항목 행**: 대표 사진, 스팟명, 검증 상태(색+아이콘/라벨 병기), 방문 완료 체크, 드래그 핸들(편집 모드).
- **`지도로 보기` 버튼 → 컬렉션 지도 뷰**: 핀 색=검증 상태, 아이콘=카테고리, 숫자=클러스터. (PRD §12)
- **공개범위 컨트롤**: `PRIVATE`(기본) ⇄ `LINK`(링크 아는 사람 열람) 전환 + 링크 복사.
- **새 컬렉션 폼**: 제목·설명·공개범위·커버.

## 인터랙션 흐름
```
스팟 카드/상세 → 원탭 저장 → (비로그인이면 소프트 게이트)
  → 기본함 '저장됨' 자동 저장 + 저장 바텀시트 열림
    → (선택) 컬렉션 선택/해제 → 다대다로 저장
    → (선택) 새 컬렉션 만들기 → 생성 후 해당 스팟 추가

컬렉션 탭 → 컬렉션 목록 → 컬렉션 상세
  → 순서 편집(드래그 앤 드롭) → order 반영
  → 지도로 보기 → 저장 스팟 핀 일괄 표시 → 핀 탭 → 스팟 상세
  → 공개범위 전환(PRIVATE ⇄ LINK) → 링크 공유
  → (현장 방문·인증 누적) → 진행률 바 갱신 → 전부 완료 시 완주 표시
```

## 엣지 케이스
- **비로그인 저장/생성 시도**: 소프트 게이트 로그인 요구. 로그인 후 원래 저장 액션 이어감. (PRD §8, [`../01-auth-onboarding/spec.md`](../01-auth-onboarding/spec.md))
- **이미 저장된 스팟 재저장**: 동일 컬렉션 중복 추가 방지(토글은 해제로 동작). 서로 다른 컬렉션에는 중복 저장 허용(다대다).
- **기본함 `저장됨`**: 삭제·이름변경 불가. 목록에서 항상 상단/고정 노출(정렬 규칙은 TODO).
- **컬렉션에서 스팟 제거 vs 저장 해제**: 특정 컬렉션에서 항목 제거는 다른 컬렉션·`저장됨` 저장 상태에 영향 없음.
- **삭제·숨김된 스팟이 항목에 포함**: 항목을 비활성/플레이스홀더로 표시(진행률 분모 처리 규칙은 TODO). (PRD §38)
- **빈 컬렉션 지도 보기**: 핀 없음 → 빈 상태 안내.
- **`LINK` → `PRIVATE` 재전환**: 기존 링크 열람 차단. 링크 토큰 무효화/재발급 정책은 TODO.
- **`isOfficial` 컬렉션**: 일반 사용자에게 편집·삭제·순서 컨트롤 미노출(열람·저장 파생만).
- **동시 편집(다기기)**: 순서/항목 충돌 처리 정책 TODO.

## 인수 조건 (Given/When/Then)
- **Given** 로그인 사용자가 스팟 카드에서, **When** 원탭 저장하면, **Then** 기본함 `저장됨`에 자동 저장되고 버튼이 저장 상태로 바뀐다.
- **Given** 저장 바텀시트에서, **When** `새 컬렉션 만들기`로 컬렉션을 만들어 선택하면, **Then** 해당 스팟이 새 컬렉션에 추가된다.
- **Given** 한 스팟이 이미 A 컬렉션에 있을 때, **When** B 컬렉션에도 저장하면, **Then** 두 컬렉션 모두에 저장된다(다대다, 중복 허용).
- **Given** 컬렉션 상세에서, **When** 항목을 드래그하여 재정렬하면, **Then** `order`가 갱신되어 다음 진입에도 순서가 유지된다.
- **Given** 컬렉션 상세에서, **When** `지도로 보기`를 누르면, **Then** 저장된 스팟들이 촬영자 위치 핀으로 한 번에 표시된다.
- **Given** 컬렉션의 모든 스팟에 방문 인증이 완료된 상태, **When** 상세에 진입하면, **Then** 진행률이 100%로 표시되고 완주 표시가 나타난다.
- **Given** 비로그인 사용자가, **When** 저장을 시도하면, **Then** 소프트 게이트 로그인이 요구된다(열람은 계속 가능).
- **Given** `PRIVATE` 컬렉션의 소유자가, **When** `LINK` 공개로 전환하면, **Then** 링크 소지자가 읽기 전용으로 열람할 수 있다.

## 관련 API / 데이터
- **엔티티** (PRD §15, [`../../glossary.md`](../../glossary.md)):
  - `Collection`: 소유자, 제목, 설명, 공개범위(`PRIVATE`/`LINK`), `isOfficial`(운영자 큐레이션 플래그), 커버. 기본함 `저장됨` 포함.
  - `CollectionItem`: 스팟 참조, `order`(정렬), `day`(nullable, 후속 날짜 일정 확장 여지 — MVP 미사용).
  - 참조: `Spot`(`shooterLat`/`shooterLng`, `verificationStatus`, 카테고리), `CheckIn`(진행률 소스), `City`.
- **서버 액션/API**(시그니처·권한 상세는 데이터·API 문서로): 컬렉션 CRUD, 스팟 저장/해제, 항목 순서 재정렬, 공개범위 변경, 컬렉션 진행률 조회, 컬렉션 지도용 스팟 좌표 조회. 필드·관계: [`../../data-model.md`](../../data-model.md) · 시그니처·권한: [`../../api-surface.md`](../../api-surface.md). (PRD §35·§37)
