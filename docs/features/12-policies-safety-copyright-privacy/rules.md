# 정책 · 안전 · 저작권 · 개인정보 — 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 불변식 (Invariants)
- 서비스는 **작품 원본 스틸을 직접 호스팅하지 않는다**(prd §24). before/after 슬라이더 소스는 **스팟 대표 사진(실촬영) ↔ 내 사진**뿐이다.
- 외부 지오태그 시딩(`SpotLead`)은 **좌표·장소명·출처 URL 등 메타데이터만** 저장한다. 원본 이미지/영상은 재호스팅하지 않는다(prd §24, glossary).
- 방문 인증은 **결과만** 저장한다. 원시 좌표 이력은 보관하지 않는다(prd §23).
- 업로드 사진의 **위치 EXIF는 서버 저장 전 제거**한다(prd §23).
- 실시간 위치는 **방문 인증 시에만** 사용한다(prd §23).
- 스팟 등록 시 **안전 태그 체크는 필수**다. 철도 선로 등 **고위험 유형은 등록 차단**이다(prd §25).
- 위험 스팟은 **경고 배너·주의사항을 필수 노출**한다(prd §25). 색만으로 위험을 전달하지 않는다(색+아이콘/라벨, prd §30).
- 가입 시 **이용약관·개인정보·위치기반서비스 필수 동의 + 만 14세 이상**이어야 계정을 생성한다(한국 위치정보법 대응, prd §23).
- 권리자 삭제 요청(notice & takedown) 대상 콘텐츠는 **즉시 삭제**한다(prd §24).

## Do / Don't
- ✅ before/after 소스·`SpotLead` 출처는 UI에 **출처 라벨**로 명시한다.
- ✅ 위치기반서비스 **법적 동의(가입 시)**와 **브라우저 위치 권한(인증 시점)**을 분리해 처리한다(prd §23).
- ✅ 신고 사유에 **사유지 침해·민폐**를 포함한다(prd §22).
- ✅ 스팟에 **촬영 매너 고지**를 노출한다(prd §25).
- ❌ 작품 원본 스틸을 업로드·호스팅하거나 슬라이더 소스로 쓰지 않는다.
- ❌ 외부 콘텐츠의 원본 이미지/영상을 복제·재호스팅하지 않는다.
- ❌ 원시 GPS 좌표 이력·업로드 사진의 위치 EXIF를 저장하지 않는다.
- ❌ 안전 태그 미체크·고위험 유형 스팟을 통과시키지 않는다.
- ❌ **prd에 없는 법률적 단정(적법성 보장·면책 문구 등)을 새로 만들지 않는다.** 불명확한 것은 TODO로 남긴다.

## 데이터·권한 규칙
- `GUEST`/`USER`: 동의·경고·출처 표시 열람, 동의/등록/신고 수행(prd §36).
- `MODERATOR`/`ADMIN`: 신고·권리자 삭제 요청 처리, 위험 스팟 검수, 삭제 실행([`../11-admin-moderation/`](../11-admin-moderation/)).
- `SpotLead`: 운영자 검증 전 상태. 좌표·장소명·출처 URL만 보유, 원본 이미지 없음(glossary).
- `User` 동의 이력(약관·개인정보·위치기반 동의 시각·버전), 연령 확인 필드: 정의는 [`../../data-model.md`](../../data-model.md)(미정 시 아래 TODO).
- `Spot` 안전 태그·위험 여부·주의사항 필드: 정의는 [`../../data-model.md`](../../data-model.md)(미정 시 아래 TODO).
- `Report` 사유 enum: 부정확한 위치 / 저작권 / 사유지 침해·민폐 / 부적절(prd §22).
