# 정책 · 안전 · 저작권 · 개인정보 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
서비스 전역에 걸친 **정책성 요구사항**(저작권·위치정보/개인정보·안전/사유지/민폐)을 한곳에 정의한다. 이 메뉴는 단일 화면이 아니라 여러 기능 화면에 삽입되는 **동의·경고·출처 표시 UI와 정책 규칙의 원천**이다. 상위 결정은 prd §23(개인정보·위치정보)·§24(저작권)·§25(안전·사유지)를 따르며, 이 문서는 그 결정을 화면·데이터 관점으로 구체화한다. prd에 없는 법률적 단정은 새로 만들지 않는다(미결정은 [`./rules.md`](./rules.md) TODO).

## 진입점 / 사용자
정책 UI는 개별 탭이 아니라 다음 진입점에 **삽입**된다.
- **가입 동의** — 신규 가입 흐름에서 1회. 담당 화면: [`../01-auth-onboarding/`](../01-auth-onboarding/).
- **위치 권한 목적 고지** — 방문 인증(`CheckIn`) 시도 시점. 담당 화면: [`../07-gps-checkin/`](../07-gps-checkin/).
- **스팟 등록 안전 태그·고위험 차단** — 스팟 제보 등록 폼. 담당 화면: [`../10-spot-registration/`](../10-spot-registration/).
- **위험 경고 배너·주의사항·촬영 매너 고지** — 스팟 상세. 담당 화면: [`../04-spot-detail/`](../04-spot-detail/).
- **before/after 슬라이더 출처 라벨** — 스팟 상세 비교 슬라이더. 담당 화면: [`../04-spot-detail/`](../04-spot-detail/).
- **업로드 사진 EXIF 위치 제거** — 사진 업로드. 담당 화면: [`../09-community-feed-upload/`](../09-community-feed-upload/).
- **신고(사유지 침해·민폐 포함)·권리자 삭제 요청(notice & takedown)** — 신고/검수. 담당 화면: [`../11-admin-moderation/`](../11-admin-moderation/) (prd §22).

**사용자**
- `GUEST`/`USER`: 동의·경고·출처 표시를 열람하고 동의/등록/신고 액션을 수행(권한은 prd §36).
- `MODERATOR`/`ADMIN`: 신고·권리자 삭제 요청 처리, 위험 스팟 검수. 범위: [`../11-admin-moderation/`](../11-admin-moderation/).
- 권리자(외부): notice & takedown 삭제 요청 주체. 처리는 운영자 경유.

## 화면 상태 (동의·경고 UI 등)
1. **가입 필수 동의 화면** — 이용약관·개인정보·위치기반서비스 동의 + 만 14세 이상 확인. 필수 동의 미완료 시 가입 불가(한국 위치정보법 대응, prd §23). 세부 UI는 [`../01-auth-onboarding/`](../01-auth-onboarding/).
2. **위치 권한 목적 고지** — 방문 인증 시점에 "왜 실시간 위치가 필요한지" 고지 후 브라우저 위치 권한 요청. 위치기반서비스 **법적 동의(가입 시)**와 **브라우저 위치 권한(인증 시점)**은 별개(prd §23).
3. **스팟 등록 안전 태그 체크** — 등록 시 안전 태그(사유지 / 철도 / 차도 / 영업장) 체크 **필수**(prd §25).
4. **고위험 유형 등록 차단** — 철도 선로 등 고위험 유형은 등록 차단 + 사유 안내(prd §25).
5. **위험 스팟 경고 배너 · 주의사항** — 위험 태그가 있는 스팟 상세에 경고 배너와 주의사항을 **필수** 노출(prd §25).
6. **촬영 매너 고지** — 스팟에 촬영 매너 안내 문구(prd §25).
7. **before/after 슬라이더 출처 라벨** — 슬라이더 소스는 **스팟 대표 사진(실촬영) ↔ 내 사진**임을 라벨로 명시. 작품 원본 스틸은 소스로 쓰지 않음(prd §24).
8. **SpotLead 출처 표시** — 외부 지오태그 시딩으로 만들어진 후보는 좌표·장소명·출처 URL 등 **메타데이터만** 표시하고 원본 이미지/영상은 표시·재호스팅하지 않음(prd §24, `SpotLead`).
9. **신고 사유 선택** — 부정확한 위치 / 저작권 / 사유지 침해·민폐 / 부적절(prd §22).

## 구성 요소
- **동의 항목**: `agreeTerms`(이용약관) · `agreePrivacy`(개인정보) · `agreeLocation`(위치기반서비스) + 만 14세 이상 확인(식별자·정의는 [`../01-auth-onboarding/`](../01-auth-onboarding/) 및 [`../../data-model.md`](../../data-model.md)).
- **안전 태그**: 사유지 / 철도 / 차도 / 영업장 (필드 정의는 [`../../data-model.md`](../../data-model.md) — 미정 시 TODO).
- **고위험 차단 규칙**: 철도 선로 등 고위험 유형 등록 차단(차단 대상 전체 목록은 TODO).
- **위험 경고 배너 + 주의사항**: 스팟 상세 상단 고정 표시. 색만으로 정보 전달 금지(색+아이콘/라벨 병기, prd §30).
- **촬영 매너 고지 문구**.
- **비교 슬라이더 출처 라벨**: 좌(스팟 대표 사진 · 실촬영) / 우(내 사진).
- **`SpotLead` 메타데이터**: 좌표(`shooterLat/Lng` 후보) · 장소명 · 출처 URL. 원본 이미지 미저장(glossary).
- **EXIF 스트립 처리**: 업로드 사진의 위치 EXIF를 서버 저장 전 제거(prd §23).
- **신고 사유 enum**: 부정확한 위치 / 저작권 / 사유지 침해·민폐 / 부적절(prd §22).
- **notice & takedown 처리 항목**: 권리자 삭제 요청 → 운영자 검수 큐(`ModerationQueue`) → 즉시 삭제(prd §24).

## 인터랙션 흐름
```
[가입]     신규 가입 → 필수 동의(약관·개인정보·위치기반)+만14세 확인 → 완료 시 계정 생성 / 미완료 시 차단
[인증]     방문 인증 진입 → 위치 목적 고지 → 브라우저 위치 권한 요청 → 인증 결과만 저장(원시 좌표 이력 미보관)
[등록]     스팟 제보 → 안전 태그 체크(필수) → 고위험 유형이면 등록 차단 / 아니면 제출
[열람]     위험 태그 스팟 상세 → 경고 배너·주의사항·촬영 매너 고지 노출
[업로드]   사진 선택 → 서버 업로드 → EXIF 위치 제거 후 저장
[비교]     스팟 상세 → before/after 슬라이더(스팟 대표 사진 ↔ 내 사진, 출처 라벨)
[시딩]     외부 지오태그 → SpotLead(좌표·장소명·출처 URL만) 생성, 원본 이미지 미수집 → 운영자 검증
[신고]     스팟/게시물 신고(사유 선택) → 통합 검수 큐 → 운영자 판단
[takedown] 권리자 삭제 요청 → 운영자 확인 → 해당 콘텐츠 즉시 삭제
```
각 흐름의 화면 세부는 해당 담당 화면 문서를 따르고, 이 문서는 정책 규칙(무엇을 반드시 노출·저장·차단·삭제하는가)만 확정한다.

## 엣지 케이스
- **가입 시 필수 동의 일부 거부**: 계정 생성 안 됨(prd §23, [`../01-auth-onboarding/`](../01-auth-onboarding/)).
- **만 14세 미만 표시**: 가입 차단 + 안내(prd §23).
- **위치기반서비스 동의는 했으나 브라우저 위치 권한 거부**: 방문 인증만 불가, 열람·저장은 유지(권한 별개, prd §23).
- **안전 태그 미체크 상태로 제출**: 등록 제출 차단(필수 항목).
- **고위험 유형(철도 선로 등)인데 사용자가 우회 등록 시도**: 등록 차단, 사유 안내(prd §25).
- **위험 태그 스팟에 경고 배너 누락 불가**: 위험 태그가 있으면 배너·주의사항은 항상 노출.
- **EXIF 제거 실패**: 위치 EXIF 제거를 보장할 수 없으면 저장하지 않음(원시 위치 유출 방지 — 처리 상세는 TODO).
- **외부 시딩 원본 이미지 유입 시도**: `SpotLead`에는 메타데이터만, 원본 이미지/영상 재호스팅 금지(prd §24).
- **권리자 삭제 요청 대상이 이미 승격된 스팟(대표 사진 포함)**: 요청 대상 콘텐츠를 즉시 삭제, 스팟 자체 처리(반려/유지)는 운영자 판단([`../11-admin-moderation/`](../11-admin-moderation/)).
- **외부 지오태그 시딩의 법적 적합성 미확정**: 법률 검토 전까지 운영자 수동 확인 기반으로 제한 운영(prd §41 → [`./rules.md`](./rules.md) TODO).

## 인수 조건 (Given/When/Then)
- **Given** 신규 가입, **When** 필수 동의(이용약관·개인정보·위치기반서비스) 또는 만 14세 확인을 완료하지 않음, **Then** 계정이 생성되지 않는다.
- **Given** 스팟 제보 등록, **When** 안전 태그(사유지/철도/차도/영업장)를 체크하지 않고 제출, **Then** 등록이 차단된다.
- **Given** 등록하려는 스팟이 고위험 유형(철도 선로 등), **When** 제출, **Then** 등록이 차단되고 사유가 안내된다.
- **Given** 위험 안전 태그가 있는 스팟, **When** 스팟 상세를 열람, **Then** 경고 배너와 주의사항이 노출된다.
- **Given** 사용자가 사진을 업로드, **When** 서버에 저장, **Then** 위치 EXIF가 제거된 뒤 저장된다.
- **Given** 방문 인증이 완료됨, **When** 서버가 저장, **Then** 인증 결과만 저장되고 원시 좌표 이력은 보관되지 않는다.
- **Given** 외부 지오태그 콘텐츠 시딩(`SpotLead`), **When** 수집·저장, **Then** 좌표·장소명·출처 URL 등 메타데이터만 저장되고 원본 이미지/영상은 재호스팅되지 않는다.
- **Given** 권리자의 삭제 요청(notice & takedown), **When** 운영자가 확인, **Then** 해당 콘텐츠를 즉시 삭제한다.
- **Given** before/after 슬라이더, **When** 스팟 상세에서 표시, **Then** 소스는 스팟 대표 사진(실촬영)과 내 사진이며 작품 원본 스틸은 사용되지 않는다.

## 관련 API / 데이터
- `User` — 동의 이력(약관·개인정보·위치기반 동의 시각·버전), 연령 확인. 필드 정의: [`../../data-model.md`](../../data-model.md)(미정 시 TODO).
- `Spot` — 안전 태그, 위험 여부, 주의사항, `checkinRadiusM`, `verificationStatus`, 대표 사진. 필드: [`../../data-model.md`](../../data-model.md).
- `SpotLead` — 좌표·장소명·출처 URL 등 외부 시딩 메타데이터, 원본 이미지 미저장(glossary, prd §24).
- `CheckIn` — 인증 결과만 저장, 원시 좌표 이력 미보관(prd §23).
- `Post` / `PostImage` — EXIF 위치 제거 후 저장(prd §23, [`../09-community-feed-upload/`](../09-community-feed-upload/)).
- `Report` — 사유 enum(부정확한 위치/저작권/사유지 침해·민폐/부적절), `ModerationItem`·`ModerationQueue` 경유 처리(prd §22, [`../11-admin-moderation/`](../11-admin-moderation/)).
- 시그니처·권한: [`../../api-surface.md`](../../api-surface.md).

## Phase
6 (정책·품질: 저작권/안전/약관 · 성능 · 접근성 · 분석, prd §40). 단, 개별 정책 UI는 그 기능이 구현되는 Phase에서 함께 반영된다 — 가입 동의(Phase 0) · EXIF 제거/신고(Phase 4) · 안전 태그·고위험 차단(Phase 4, 등록) · 위치 목적 고지(Phase 3, 인증). Phase 6은 이들 정책의 **통합 점검·문서화·누락 보강** 단계다.
