# 검색 · 필터 · 정렬 — 규칙 (rules)

## 불변식 (Invariants)
- 검색/필터/정렬 결과는 **지도·피드 양쪽에 동일하게 반영**한다(한쪽만 갱신 금지).
- 기본 검색 범위 = **선택 도시**. 범위 확장은 '전체에서 검색' 토글로만.
- 기본 정렬 = **인기순**.
- 인기 지표 정의 고정: **저장수 + 인증수 + 연결 게시물 좋아요 합산 파생**. 가중치·구성 변경은 PRD 개정 없이는 금지.
- 검색 대상 4종 고정: 스팟명 · 작품명 · 촬영 대상/랜드마크 · 지역.
- 정렬 3종 고정: 인기순 · 거리순 · 최신순.
- 검증 상태 필터 값 = 용어집 4종(`OFFICIAL` · `USER_VERIFIED` · `USER_REPORTED` · `ESTIMATED`).

## Do / Don't
- ✅ 검색·필터·정렬은 GUEST 포함 열람 자유로 둔다(로그인 게이트 없음).
- ✅ 위치는 '지금 내 주변'·거리순에 한해, 목적 고지 후 질의에만 사용한다.
- ✅ 검증 상태는 색만이 아니라 아이콘/라벨을 병기한다(PRD §30 접근성).
- ❌ 위치 권한을 검색 진입 조건으로 강제하지 않는다.
- ❌ 원시 좌표 이력을 저장하지 않는다(PRD §23).
- ❌ 필터·정렬을 지도/피드 한쪽에만 적용하지 않는다.

## 데이터·권한 규칙
- GUEST·USER 모두 검색·필터·정렬 열람 가능(권한 차등 없음).
- 삭제·숨김(신고 임계 초과 임시 숨김) 스팟은 결과에서 제외.
- 도시 내/전체 범위는 서버 질의 파라미터로 처리.
- '지금 내 주변' = PostGIS 반경 질의(PRD §12), 결과 좌표는 촬영자 위치(`shooterLat/Lng`).

## 정책 연동
- 위치·개인정보: PRD §23 준수(전송·질의에 한하며 원시 좌표 이력 미보관). 상세: [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/).
- 소프트 게이트 정책: [`../01-auth-onboarding/`](../01-auth-onboarding/) (검색 자체는 게이트 없음, 결과에서의 저장·인증 등 액션에만 적용).
- 숨김·신고 처리: [`../11-admin-moderation/`](../11-admin-moderation/).
- 접근성(색+아이콘/라벨): PRD §30.
