# 검색 · 필터 · 정렬 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
탐색 탭에서 스팟을 **검색·필터·정렬**로 좁혀 발견하도록 한다. 검색 대상은 스팟명·작품명·촬영 대상/랜드마크·지역이며, 결과는 **지도와 피드 양쪽에 동일하게 반영**한다(PRD §19).

## 진입점 / 사용자
- **진입점**: 탐색 탭 상단의 검색창·필터(정보구조 §탐색). 지도⇄피드 어느 뷰에서도 동일 검색/필터/정렬을 공유한다.
- **사용자**: GUEST 포함 전원 열람 자유(검색·필터·정렬에 소프트 게이트 없음). 대표 페르소나 — P1(여행 전 계획: 도시 내 검색·필터), P3(현장: '지금 내 주변'·거리순).

## 화면 상태
| 상태 | 설명 |
|---|---|
| 기본(검색어 없음) | 선택 도시 기준 피드/지도(탐색 기본 화면). 필터·정렬 컨트롤 노출 |
| 입력 중 | 검색어 입력. 자동완성/최근 검색어 노출 여부는 TODO |
| 결과 있음 | 매칭 스팟을 지도(핀)·피드(카드) 양쪽에 반영 |
| 결과 없음 | 빈 상태 + '전체에서 검색' 확장 또는 필터 해제 유도 |
| 로딩 | 질의 진행 중 스켈레톤/스피너 |
| 위치 필요 | '지금 내 주변'/거리순 선택 시 위치 권한 요청 · 거부 시 폴백 안내 |
| 오프라인/에러 | 지도 로드 실패 시 피드 폴백, 재시도 안내 |

## 구성 요소
- **검색창**: 검색 대상 4종 = 스팟명(`Spot`) · 작품명(`Work`) · 촬영 대상/랜드마크(`subject`) · 지역(도시/지역).
- **검색 범위 토글**: 선택 도시 내(기본) ⇄ **전체에서 검색**.
- **필터**:
  - 카테고리(`Category`)
  - 검증 상태(`verificationStatus`: `OFFICIAL` · `USER_VERIFIED` · `USER_REPORTED` · `ESTIMATED`) — 색 + 아이콘/라벨 병기.
  - 작품(`Work`)
  - 시간대(야경 · 일몰 · 일출) — 매핑 스팟 필드/판정 기준은 TODO.
  - **지금 내 주변**(현재 위치 기준 반경 질의, PostGIS).
- **정렬 선택기**: 인기순(기본) · 거리순 · 최신순.
  - 인기 = **저장수 + 인증수 + 연결 게시물 좋아요 합산 파생 지표**(PRD §16, 용어집).
- **결과 표시면**: 지도(핀) + 피드(카드). 검색/필터/정렬은 두 뷰에 동시 반영.

## 인터랙션 흐름
1. **검색**: 검색창 입력 → 대상 4종 매칭 → 결과를 지도·피드에 갱신.
2. **범위 전환**: 도시 내 ↔ '전체에서 검색' 토글 → 결과 재질의.
3. **필터 적용/해제**: 카테고리·검증상태·작품·시간대·내 주변 선택 → 결과 갱신.
4. **정렬 변경**: 인기(기본) → 거리 → 최신 전환.
5. **지금 내 주변**: 위치 권한 요청 → 허용 시 반경 질의, 거부 시 도시 내 검색으로 폴백.
6. **초기화**: 검색어/필터/정렬 리셋 → 도시 기본 화면 복귀.

## 엣지 케이스
- 위치 권한 거부/불가: '지금 내 주변'·거리순 비활성, 안내 후 도시 내 검색으로 폴백.
- 도시 내 결과 없음(전체엔 있음): '전체에서 검색' 확장 유도.
- 어떤 범위에서도 결과 없음: 빈 상태 + 필터 해제 유도.
- 검색어 없이 필터만 적용: 필터 결과만 표시.
- 오프라인/지도 로드 실패: 피드 폴백 + 재시도(지도 미반영 상태 안내).
- 삭제/숨김(신고 임계 초과 임시 숨김) 스팟: 결과에서 제외.

## 인수 조건 (Given/When/Then)
- **Given** 도시 선택 상태, **When** 검색창에 스팟명을 입력, **Then** 선택 도시 내 매칭 결과가 지도·피드 양쪽에 반영된다.
- **Given** 도시 내 결과가 없음, **When** '전체에서 검색'을 토글, **Then** 도시 범위를 벗어난 결과가 표시된다.
- **Given** 정렬 미변경, **When** 결과가 표시, **Then** 기본 정렬은 인기순(저장+인증+좋아요 파생)이다.
- **Given** 필터 없음, **When** 검증상태=`OFFICIAL` 필터 적용, **Then** `OFFICIAL` 스팟만 결과에 남는다.
- **Given** 위치 권한 거부, **When** '지금 내 주변' 또는 거리순을 시도, **Then** 안내와 함께 도시 내 검색으로 폴백한다.

## 관련 API / 데이터
- **엔티티**: `Spot`(스팟명·`subject`·도시/지역·`Category`·`verificationStatus`·추천 시간대·저장/인증/좋아요 집계), `Work`(작품명), `Category`, `City`, `Post`/`Like`·`CheckIn`(인기 지표 산출).
- **주변 검색**: 현재 위치 기준 반경 쿼리(PostGIS, PRD §12).
- **인기 지표**: 저장수 + 인증수 + 연결 게시물 좋아요 합산 파생(PRD §16).
- 검색/필터/정렬 API 시그니처·필드 상세는 데이터 모델/API 문서에서 확정(TODO, `rules.md` 참조).
