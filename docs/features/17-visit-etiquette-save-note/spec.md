# 방문 매너 배너 · 저장 출처 메모 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) §28-10 · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)
> **포스트-MVP**. 두 하위 기능은 PRD §28-10에서 한 항목으로 묶인다 — (a) 방문 매너 배너(스팟 상세), (b) 저장 출처 메모(컬렉션 저장).

## 목적
- **(a) 방문 매너 배너**: 스팟 상세 상단에 **방문·촬영 매너**(성지 순례 예절·사유지 배려·소음·쓰레기 등)를 1급 요소로 노출한다. 성지 순례 앱들이 매너 가이드를 동봉해 호평받는 지점(聖地巡礼マップ 벤치마크)을 반영하되, **위험을 알리는 안전 경고 배너**(prd §25)와는 **시각·의미를 명확히 구분**한다. 매너 = "배려", 안전 = "위험".
- **(b) 저장 출처 메모**: 스팟을 컬렉션에 저장할 때 **한 줄 메모**(`CollectionItem.note`)를 남겨 "어디서 봤는지·왜 저장했는지"를 기억한다. 저장이 쌓이면 출처를 잊는 구글맵 저장의 최대 불만을 해소한다. 기본 개인 전용.

## 진입점 / 사용자
- **(a) 배너 진입점**: 스팟 상세([`../04-spot-detail/spec.md`](../04-spot-detail/spec.md)) 진입 시 매너 텍스트가 있으면 상단 자동 노출. 별도 액션 없음(열람).
- **(b) 메모 진입점**: 원탭 저장 → **저장 바텀시트**([`../06-collections-planning/spec.md`](../06-collections-planning/spec.md))의 메모 입력란.
- **사용자 역할** (prd §36):
  - `GUEST`: 매너 배너 **열람**. 저장 메모는 저장 자체가 소프트 게이트라 로그인 후 사용.
  - `USER`/`TRUSTED_USER`: 매너 배너 열람 + 저장 메모 작성·수정.
  - `MODERATOR`/`ADMIN`: 매너 텍스트는 마스터데이터로 관리(어드민, 11).

## 화면 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| 매너 배너 있음 | 스팟에 매너 텍스트 존재 | 상세 상단 **매너 배너**(안전 경고와 구분되는 톤·아이콘) |
| 매너 배너 없음 | 매너 텍스트 미입력 | 배너 자리 숨김(빈 배너 금지) |
| 안전+매너 공존 | 위험 스팟 + 매너 텍스트 | **안전 경고 배너 최상단, 매너 배너는 그 아래** 별도 위계 (prd §25·§30) |
| 저장 메모 입력 | 저장 바텀시트 | 선택 입력 한 줄(플레이스홀더: 예 "OO 유튜버 추천") |
| 저장 메모 표시 | 컬렉션 항목에 메모 존재 | 컬렉션 상세의 해당 스팟 행에 메모 노출(소유자·허용 뷰에서) |
| 메모 비어 있음 | 메모 미입력 | 메모 자리 숨김 |

## 인터랙션 흐름
```
[방문 매너 배너]
스팟 상세 진입 → 매너 텍스트 있으면 상단 배너 자동 노출
  → (위험 스팟이면) 안전 경고 배너가 최상단, 매너 배너는 아래 별도 위계

[저장 출처 메모]
스팟 원탭 저장 → (GUEST 소프트 게이트) → 저장 바텀시트
  → 컬렉션 선택/생성 + (선택) 한 줄 출처 메모 입력
  → 저장 → 컬렉션 상세에서 스팟 행에 메모 표시(소유자 뷰)
  → 메모 수정/삭제는 컬렉션 항목 편집에서
```

## 엣지 케이스
- **매너·안전 동시 존재**: 두 배너를 **다른 위계·색·아이콘**으로 분리(혼동 금지). 안전이 항상 상위.
- **매너 텍스트 없음**: 배너 숨김(빈 배너·"매너 정보 없음" 나열 금지).
- **저장 메모 미입력**: 저장은 정상 완료, 메모 자리 숨김.
- **같은 스팟을 여러 컬렉션에 저장**: 메모는 **`CollectionItem` 단위**(컬렉션×스팟)로 각각 보관 — 컬렉션마다 다른 메모 가능.
- **공개(`LINK`) 컬렉션의 메모 노출**: 기본 개인 전용. 공개 뷰 노출 여부는 미정(TODO) — 확정 전에는 **비노출**(보수적).
- **긴 메모·개행·이모지**: 한 줄 제한·트리밍, 최대 길이 초과 입력 차단(길이 TODO).
- **부적절한 메모 내용**: 개인 전용이라 신고 대상 아님. 공개 노출을 허용하게 되면 운영 정책(22) 연동 필요(TODO).

## 인수 조건 (Given/When/Then)
- **Given** 매너 텍스트가 있는 스팟, **When** 상세에 진입, **Then** 상단에 **방문 매너 배너**가 노출되고, 안전 경고 배너와 **색만이 아니라 색+아이콘+라벨로 구분**된다 (prd §30).
- **Given** 위험 스팟이면서 매너 텍스트도 있음, **When** 상세를 표시, **Then** **안전 경고 배너가 최상단**, 매너 배너는 그 아래 별도 위계로 표시된다 (prd §25).
- **Given** 로그인 사용자가 스팟을 저장, **When** 저장 바텀시트에서 한 줄 메모를 입력, **Then** 그 메모가 `CollectionItem.note`로 저장되고 컬렉션 상세의 해당 스팟 행에 표시된다.
- **Given** 같은 스팟을 두 컬렉션에 저장, **When** 각 컬렉션에서 다른 메모를 입력, **Then** 메모는 **컬렉션×스팟 단위로 독립** 보관된다.
- **Given** 메모가 있는 스팟이 담긴 공개(`LINK`) 컬렉션, **When** 비소유자가 링크로 열람, **Then** (기본 정책) 메모는 **노출되지 않는다**(개인 전용).
- **Given** 매너 텍스트가 없는 스팟, **When** 상세를 표시, **Then** 매너 배너는 렌더링되지 않는다.
