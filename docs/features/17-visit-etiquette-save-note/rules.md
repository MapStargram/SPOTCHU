# 방문 매너 배너 · 저장 출처 메모 — 개발·도메인 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) §28-10 · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)
> **포스트-MVP**. 착수 전 이 문서의 TODO/미결정(특히 필드·공개범위)을 먼저 해소한다.

## 불변식
- **방문 매너 배너와 안전 경고 배너는 별개다.** 매너 = 배려(예절·사유지·소음·쓰레기), 안전 = 위험(사유지 침해·철도·차도·영업장, prd §25). 두 배너는 **다른 위계·색·아이콘**으로 구분하며, 위험 스팟에서는 **안전 경고가 항상 상위**다.
- 배너·메모는 **색만으로 정보를 전달하지 않는다** — 색+아이콘+라벨 병기 (prd §30).
- `CollectionItem.note`는 **컬렉션×스팟(`CollectionItem`) 단위**로 보관된다. 같은 스팟이라도 컬렉션마다 메모가 다르다(다대다, prd §15).
- 저장 출처 메모는 **기본 개인 전용**이다. 공개(`LINK`) 컬렉션에서의 노출 여부가 확정되기 전에는 **노출하지 않는다**(보수적 기본).
- 매너 텍스트의 원천은 **등록자·운영자**(마스터데이터)다. 저장 메모의 원천은 **저장한 사용자 개인**이다. 둘을 섞지 않는다.
- 선택 필드가 비면 해당 배너·메모 자리를 **숨긴다**(빈 배너·"정보 없음" 나열 금지, 04 규칙과 정합).

## Do / Don't
- **Do** 위험 스팟에서 안전 경고를 최상단에, 매너 배너를 그 아래 별도 위계로 배치한다.
- **Do** 매너 배너를 안전 경고와 **한눈에 구분되는 톤**(예: 정보/안내 vs 경고)으로 디자인한다.
- **Do** 저장 메모를 저장 바텀시트의 **선택** 입력으로 둔다(입력 강제 금지, 저장은 메모 없이도 완료).
- **Do** 메모는 한 줄로 트리밍하고 최대 길이를 서버에서 검증한다(길이 TODO).
- **Don't** 매너 배너를 안전 경고와 같은 색·아이콘으로 표시해 혼동을 주지 않는다.
- **Don't** 개인 메모를 소유자·허용 범위 밖에 노출하지 않는다(공개범위 확정 전 비노출).
- **Don't** data-model에 없는 필드명을 임의로 만들지 않는다(매너 텍스트 필드는 확정 후 사용).
- **Don't** 저장 메모를 스팟 공개 데이터(대표 정보)로 승격하지 않는다(개인 컨텍스트 유지).

## 데이터·권한 규칙
- **권한** (prd §36): 매너 배너는 `GUEST` 포함 전원 열람. 저장 메모는 저장이 소프트 게이트이므로 `USER` 이상, **자신의 `CollectionItem`만** 작성·수정·삭제.
- **입력 검증**: 저장 메모는 서버에서 스키마 검증(zod) — 최대 길이·개행/제어문자 처리 (prd §5 신뢰 경계). 길이 값은 TODO.
- **매너 텍스트 관리**: 어드민 마스터데이터(11)로 운영·검수. 일반 사용자 임의 편집 대상 아님.
- **접근성** (prd §29·§30): 배너는 시맨틱 마크업·아이콘 대체텍스트·대비. 메모 입력란은 라벨·플레이스홀더 제공.
- **컬렉션 삭제·항목 제거 시** 연결된 `note`도 함께 정리(고아 메모 방지).

## 정책 연동
- 안전(prd §25): 매너 고지의 상위 정책. 매너 배너는 §25 "촬영 매너 고지"를 상세 상단 1급 요소로 승격한 것. → [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/)
- 접근성(prd §30): 색+아이콘+라벨 병기, 색 단독 금지. 두 배너 구분(prd §41-16).
- 컬렉션(prd §15): `CollectionItem.note` 추가. → [`../06-collections-planning/`](../06-collections-planning/)
- 운영(prd §22): 저장 메모가 공개로 확장될 경우에만 신고·운영 정책 연동 필요(현재 개인 전용이라 비대상).
