# GPS 방문 인증 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
현장에서 스팟 허용 반경 내 **실시간 GPS**로 방문을 인증(`CheckIn`)한다. GPS만으로 방문 완료가 가능하며 사진 업로드는 선택이다(PRD §17). 방문 인증 완료 수는 제품의 NSM(PRD §31)이며, 사용자 검증 승격(`USER_REPORTED` → `USER_VERIFIED`, PRD §18)과 게임화(배지·달성률, feature 08)의 입력이 된다.

## 진입점 / 사용자
- **진입**: 스팟 상세의 **'방문 인증' 버튼**. 별도 탭이 아니다(PRD §9, IA spec).
- **사용자**: 로그인 `USER`(PRD §8 현장 단계는 로그인 필요, §36 권한). `GUEST`가 시도하면 **소프트 게이트**로 로그인을 요구한다(glossary 소프트 게이트).
- **전제**: 위치 권한 허용. 위치는 **방문 인증 시에만** 실시간으로 사용한다(PRD §23).

## 화면 상태
| 상태 | 설명 |
|---|---|
| 초기 | 스팟 상세에서 '방문 인증' 버튼 노출 |
| 소프트 게이트 | 비로그인(`GUEST`) 시도 시 로그인 요구 |
| 위치 확인 중 | 실시간 GPS 측위 진행 |
| 성공(최초) | 허용 반경·정확도 충족, 스팟당 최초 1회 unique 인증 완료 |
| 성공(재방문) | 쿨다운 경과 후 재인증, 기록되되 통계·배지 중복 없음 |
| 실패: 반경 밖 | 거리 > `checkinRadiusM`, 남은 거리 안내 + 재시도 |
| 실패: 정확도 불량 | `accuracy` > 50m, "실외로 이동 후 재시도" |
| 보류: mock 감지 | mock location 감지 시 인증 보류, 서버 타임스탬프 기록 |
| 권한 거부 | 위치 권한 거부, 목적 재고지 + 재시도 안내 |
| 쿨다운 중 | 방문 완료한 스팟에 24h 미경과 재인증 시도 |

## 구성 요소
- **'방문 인증' 버튼** (스팟 상세 내).
- **측위 상태 인디케이터**(위치 확인 중).
- **거리/정확도 안내**: 스팟까지 남은 거리(m), 필요 반경(`checkinRadiusM`, 기본 100m), 현재 `accuracy`.
- **결과 표시**: 성공/실패/보류. 상태는 **색 + 아이콘 + 라벨 병기**(PRD §30 접근성).
- **재시도 버튼**(실패·보류·권한 거부 시).
- **(선택) 사진 업로드 진입**: 인증 후 유도. 인증 사진은 `Post.isVerifiedShot`로 표기(PRD §16, feature 09 연동).
- **배지/승격 안내**: 성공 시 게임화(feature 08) 반영 안내.

## 인터랙션 흐름
1. 스팟 상세에서 **'방문 인증'** 을 탭한다.
2. 비로그인이면 **소프트 게이트**로 로그인 후 복귀.
3. 위치 권한을 요청·획득하고 실시간 GPS로 측위한다.
4. 스팟 좌표(`shooterLat`/`shooterLng`)와의 거리 및 `accuracy`를 확인한다.
5. **판정**: 거리 ≤ `checkinRadiusM`(기본 100m) **AND** `accuracy` ≤ 50m **AND** mock 미감지 → 인증 허용.
6. 서버에 인증을 기록한다(**서버 타임스탬프**). 스팟당 최초면 unique 카운트, 재방문이면 기록만(통계·배지 중복 없음).
7. 성공 화면 표시 → (선택) 사진 업로드 유도 → 배지·검증 승격 반영.
8. 실패·보류 시 사유별 안내(아래 엣지 케이스)와 재시도를 제공한다.

## 엣지 케이스
- **반경 밖**: 남은 거리 안내 + 재시도(PRD §17).
- **정확도 불량**(`accuracy` > 50m, 실내 등): "실외로 이동 후 재시도"(PRD §17).
- **위치 권한 거부**: 목적 재고지 + 설정 안내, 인증 불가.
- **mock location 감지**: 인증 보류, 서버 타임스탬프 기록(PRD §17).
- **24h 쿨다운 중 재인증**: 남은 쿨다운 안내(PRD §17).
- **재방문(쿨다운 경과)**: 기록되되 unique 카운트·배지 중복 없음(PRD §17).
- **연타/중복 요청**: 단일 인증으로 처리, 중복 카운트 없음(PRD §38).
- **삭제·비공개된 스팟**: 인증 불가.
- **오프라인/측위 실패**: 재시도 안내.

## 인수 조건 (Given/When/Then)
- **Given** 로그인 사용자가 허용 반경 내 & `accuracy` ≤ 50m, **When** 방문 인증, **Then** 인증이 완료되고 **서버 타임스탬프**로 기록된다.
- **Given** 사용자가 스팟 허용 반경 밖, **When** 인증 시도, **Then** 인증되지 않고 **남은 거리 안내 + 재시도**를 제공한다.
- **Given** `accuracy` > 50m, **When** 인증 시도, **Then** 인증되지 않고 **"실외로 이동 후 재시도"** 를 안내한다.
- **Given** 이미 방문 완료한 스팟, **When** 24h 내 재인증, **Then** 쿨다운으로 보류되고 통계·배지에 **중복 반영되지 않는다**.
- **Given** mock location 감지, **When** 인증 시도, **Then** 인증이 **보류**되고 서버 타임스탬프가 기록된다.
- **Given** 서로 다른 사용자 3명 이상 인증이 누적된 `USER_REPORTED` 스팟, **When** 3번째 인증 완료, **Then** `USER_VERIFIED`로 자동 승격된다(PRD §18).

## 관련 API / 데이터
- **엔티티**: `CheckIn`(인증 결과·서버 타임스탬프), `Spot`(`shooterLat`/`shooterLng`, `checkinRadiusM`, `verificationStatus`), `User`, (선택) `Post`(`isVerifiedShot`). 필드 상세: [`../../data-model.md`](../../data-model.md).
- **API / 서버 액션**: 인증 생성(권한 `USER`). 시그니처·권한 상세: [`../../api-surface.md`](../../api-surface.md).
- **지표**: NSM(방문 인증 완료 수)·퍼널의 방문 인증 단계(PRD §31) → feature 14 연동.
