# 프로필 · 배지 · 게임화 — 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 용어: [`../../glossary.md`](../../glossary.md) · 스펙: [`./spec.md`](./spec.md)

## 불변식 (Invariants)
- 방문 수·도시 달성률·작품 진행률·컬렉션 완주는 **GPS 인증 unique 기준**(스팟당 최초 1회). 재방문 중복 없음([`../07-gps-checkin/`](../07-gps-checkin/), prd §17).
- MVP 배지는 **정확히 3종**: 도시 배지 · 성지순례 완주 배지 · 최초 제보자 배지. 배지 종류 추가는 PRD 개정 전까지 금지.
- 동일 배지는 사용자당 **중복 부여 금지**(멱등) — `UserBadge`는 (User, Badge) unique.
- 배지·방문 기록은 개인 데이터 → **로그인 사용자 전용**.
- 컬렉션 완주는 **진행 지표로만** 표시하며 MVP 전용 배지가 없다(배지 3종에 미포함).
- 배지 정의(`Badge`)는 **운영자 마스터 데이터**(prd §21) — 앱에서 임의 생성 금지.

## Do / Don't
- ✅ 배지 부여·지표 산정은 **서버에서 GPS 인증 이벤트 기준**으로 수행한다.
- ✅ 배지 획득 시 축하 피드백(토스트/모달) + 인앱 알림([`../13-notifications/`](../13-notifications/))을 병행한다.
- ✅ 달성률·진행률은 `CheckIn`에서 파생 재계산한다(원천 데이터 별도 저장 아님).
- ✅ 배지 상태(획득/미획득)는 색만이 아니라 **라벨/아이콘 병기**로 표시한다(prd §30 접근성).
- ❌ 클라이언트 신뢰만으로 배지를 부여하지 않는다(서버 검증 필수).
- ❌ 재방문·재인증으로 카운트를 증가시키지 않는다.
- ❌ MVP에서 정보수정 기여자 배지·시즌 한정 배지·테마 배지를 만들지 않는다(후속, prd §27).

## 데이터·권한 규칙
- `GUEST`: 프로필 개인 기록 접근 불가 → 로그인 유도(소프트 게이트).
- `USER`: 본인 방문 기록·배지·내 사진 조회. 배지 부여는 시스템 자동(사용자 조작 아님).
- `MODERATOR`/`ADMIN`: 배지 정의(`Badge`) CRUD(마스터 데이터, prd §21).
- 엔티티: `Badge`(정의), `UserBadge`(사용자↔배지, 획득 시각). 필드 상세: [`../../data-model.md`](../../data-model.md).
- `CheckIn` unique가 방문 수·도시 달성률·작품 진행률·컬렉션 완주의 **단일 산정 원천**.

## 구현 결정 (Phase-H)
- **도시 배지 임계값 = 100% 완주**: 해당 도시의 DB 존재 스팟을 모두 방문 인증 시 지급(`context=cityId`).
- **성지순례 배지 = 작품 100% 완주**: 해당 작품에 물린 스팟을 모두 방문 인증 시 지급(`context=workId`).
- **도시 달성률 분모 = 도시 전체 스팟(DB 존재분)**. `isBlockedHighRisk` 제외 여부는 후속(현재 포함).
- **지급 트리거 = `checkInAction`(first=true)**. 순수 판정 `computeCheckInAwards`(테스트됨) + DB 유니크로 멱등.
- **축하 피드백 = 체크인 성공 화면 배지 카드**(서버 지급분만 노출). 토스트/모달·인앱 알림은 후속(알림 모델 미도입).
- **잠금 배지 노출 = 노출함**(도시·작품별 카드 + 진행률 바, 획득/미획득 아이콘·라벨 병기).

## 결정된 정책
- **최초 제보자 배지 트리거(확정)**: 제보한 스팟이 **`USER_VERIFIED`로 승격되는 시점**에 제보자(`spot.createdById`)에게 지급한다(검증된 제보만 보상 → 스팸·저품질 제보 badge-farming 방지). `checkInAction`의 승격 전이(원자적 update, `promoted.count===1`) 분기에서 `awardFirstReporterBadge` 호출. `grant`는 멱등이라 제보자별 최초 1회만.
