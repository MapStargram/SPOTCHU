# 프로필 · 배지 · 게임화 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
방문 인증으로 쌓인 기록을 **프로필**에 모으고, 방문 수집을 **게임화 지표와 배지**로 보상해 재방문·재탐색 루프를 강화한다. 프로필은 "나의 기록"(방문·배지·내 사진·설정)의 진입점이며, 배지는 수집 동기를 만든다.

게임화 MVP 범위(prd §26):
- 방문한 스팟 수
- 도시별 방문 달성률
- 작품별 성지순례 진행률
- 컬렉션 완주(진행 지표 — 전용 배지 없음)
- 배지 3종: **도시 배지 · 성지순례 완주 배지 · 최초 제보자 배지**(glossary "배지" 정의)

## 진입점 / 사용자
- **진입점**: 하단 내비 5탭 중 **프로필** 탭([`../00-information-architecture/spec.md`](../00-information-architecture/spec.md)). 배지 획득 축하는 **GPS 방문 인증 직후**(스팟 상세)에도 노출.
- **사용자**:
  - `USER`(로그인): 본인 방문 기록·배지·내 사진 조회, 게임화 지표 확인.
  - `GUEST`(비로그인): 프로필의 개인 기록은 **로그인 사용자 전용**(prd §8 "기록" 단계 로그인 필요) → 소프트 게이트로 로그인 유도.
  - `MODERATOR`/`ADMIN`: 배지 정의(Badge)는 어드민 마스터 데이터로 관리(prd §21) — 본 화면 범위 밖.

## 화면 상태
- **프로필 기본(로그인)**: 방문 기록 요약(방문한 스팟 수) · 배지함 · 내가 올린 사진 · 설정 진입.
- **게임화 지표**: 도시별 방문 달성률, 작품별 성지순례 진행률, 컬렉션 완주 상태.
- **배지 획득 순간**: 축하 피드백(토스트 또는 모달) + 배지함 반영 + 인앱 알림(prd §20).
- **빈 상태**: 방문/배지/사진 없음 → 탐색·인증·업로드 유도.
- **비로그인**: 개인 기록 미표시 + 로그인 유도.
- **로딩 / 에러**: 지표·목록 로드 실패 시 재시도.

## 구성 요소
- **프로필 요약**: 방문한 스팟 수 등 기록 요약.
- **배지함(Badge case)**: 획득 배지 그리드. 배지 선택 시 조건·획득일 표시.
- **게임화 지표 영역**: 도시별 방문 달성률, 작품별 성지순례 진행률, 컬렉션 완주 상태.
- **내가 올린 사진**: 사용자 게시물 목록(상세: [`../09-community-feed-upload/spec.md`](../09-community-feed-upload/spec.md)).
- **설정 진입**: 설정 화면으로 이동.
- **축하 피드백 컴포넌트**: 배지 획득 시 토스트/모달.

## 인터랙션 흐름
1. **배지 획득**: GPS 방문 인증 완료 → 서버가 배지 조건 충족 판정 → **UserBadge 부여(1회)** → 축하 피드백(토스트/모달) → 배지함 반영 + 인앱 알림.
2. **프로필 열람**: 프로필 탭 진입 → 방문 기록·게임화 지표·배지함·내 사진 로드.
3. **배지 상세**: 배지함에서 배지 선택 → 배지 조건·획득일 확인.
4. **설정 이동**: 설정 진입 → 설정 화면.
5. **비로그인**: 프로필 탭 진입 → 로그인 유도(소프트 게이트, [`../01-auth-onboarding/`](../01-auth-onboarding/)).

## 엣지 케이스
- **재방문·재인증**: 스팟당 unique 1회만 카운트 → 방문 수·달성률·진행률·배지에 변화 없음(prd §17, [`../07-gps-checkin/`](../07-gps-checkin/)).
- **24h 쿨다운 내 재인증**: 07-gps-checkin 규칙에 따라 처리 → 통계 무변화.
- **이미 획득한 배지 조건 재충족**: 중복 부여 금지(멱등).
- **다중 배지 동시 획득**: 한 인증으로 2개 이상 조건 충족 시 표기 방식 — TODO.
- **분모 변동**: 도시/작품/컬렉션의 총 스팟 수 변화 시 달성률·진행률 재계산.
- **삭제·반려된 스팟**: 방문 기록·진행률·배지에 미치는 소급 처리 — TODO.
- **비로그인 프로필 진입**: 개인 기록 미노출 + 로그인 유도.

## 인수 조건 (Given/When/Then)
- **Given** 로그인 사용자가 특정 배지 조건(도시 달성/작품 완주/최초 제보)을 충족, **When** 해당 트리거(GPS 인증 등)가 완료, **Then** 해당 배지가 **1회** 부여되고 축하 피드백 + 배지함 반영 + 인앱 알림이 발생한다.
- **Given** 이미 방문 완료한 스팟, **When** 재방문·재인증, **Then** 방문 수·달성률·진행률·배지에 변화가 없다.
- **Given** 비로그인 사용자, **When** 프로필 탭 진입, **Then** 개인 기록 대신 로그인 유도가 표시된다.
- **Given** 어떤 작품에 연결된 스팟을 모두 방문(성지순례 진행률 100%), **When** 마지막 스팟 인증, **Then** 성지순례 완주 배지가 부여된다.
- **Given** 사용자가 배지함에서 배지를 선택, **When** 배지 상세를 연다, **Then** 배지 조건과 획득일이 표시된다.

## 관련 API / 데이터
- **엔티티**: `Badge`(배지 정의 — 유형·이름·설명·아이콘·획득 조건, 운영자 마스터 데이터), `UserBadge`(사용자↔배지, 획득 시각). 필드 상세: [`../../data-model.md`](../../data-model.md).
- **산정 원천**: `CheckIn`(GPS 인증 unique)이 방문 수·도시 달성률·작품 진행률·컬렉션 완주의 단일 산정 원천. 관련: [`../07-gps-checkin/`](../07-gps-checkin/).
- **연동**: `Work`↔`Spot` 다대다(성지순례 진행률 기준, prd §14), `Collection`/`CollectionItem`(컬렉션 완주), `Post`(내가 올린 사진).
- **API/서버 액션**: 프로필 기록 조회, 배지함 조회, 인증 이벤트 기반 배지 부여. 시그니처·권한: `../../api-surface.md`(prd §37).
