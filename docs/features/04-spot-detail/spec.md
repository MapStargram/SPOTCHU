# 스팟 상세 · 원본 비교 슬라이더 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
스팟(`Spot`) 하나의 촬영 정보 — **촬영자가 서는 위치·카메라 방향·촬영 대상·촬영 팁** — 을 정확히 전달하고, 저장·방문 인증·사진 추가·신고로 이어지는 핵심 루프의 허브 화면을 정의한다. 지도가 "장소"를 알려준다면, 이 화면은 **"어디에 서서 어느 방향으로 찍는가"** 를 알려주는 곳이다 (prd §2·§4). 비로그인 사용자도 **좌표·상세를 포함한 전 항목을 열람**할 수 있고, 액션만 소프트 게이트한다 (prd §8·§36).

## 진입점 / 사용자
- **진입점**: 탐색(지도 핀 / 피드 카드), 홈 큐레이션·인기 스팟, 작품(`Work`) 상세의 스팟 리스트, 컬렉션 항목, 검색 결과.
- **사용자 역할** (prd §36):
  - `GUEST`(비로그인): 전 항목 열람. 액션 시 소프트 게이트로 로그인 유도.
  - `USER`: 저장·방문 인증·사진 추가·신고.
  - `TRUSTED_USER`: `USER`와 동일(상세 화면에서 추가 권한 없음).
  - `MODERATOR`/`ADMIN`: 열람·액션 + 신고 처리는 별도 어드민에서(본 화면은 신고 접수만).

## 화면 상태
| 상태 | 조건 | 표시 |
|---|---|---|
| 로딩 | 데이터 페치 중 | 스켈레톤(대표 사진·지도 영역) |
| 정상 | 필수 필드 존재 | 전체 구성 요소 렌더 |
| 최소 필드 | 제보 직후 등 선택 필드 미입력 | 필수 항목만, 선택 항목 자리 숨김(빈 라벨 노출 금지) |
| 검증 상태별 | `verificationStatus` 4종 | 색+아이콘+라벨 병기 뱃지 (prd §30) |
| `ESTIMATED` | 위치 추정·미확인 | "위치 추정" 명시 배너로 신뢰도 구분 (glossary) |
| 위험 스팟 | 안전 태그(사유지/철도/차도/영업장) 있음 | **경고 배너 + 주의사항 필수 노출** (prd §25) |
| 삭제·병합됨 | 스팟이 삭제/다른 스팟으로 병합 | 안내 + (병합 시) 대상 스팟으로 이동 유도 (prd §38) |
| 오프라인·지도 실패 | 지도 로드 실패 | 좌표·정적 폴백 안내, 나머지 상세는 표시 (prd §12) |

|---|---|---|
| 저장 | `Collection`, `CollectionItem` | **원탭 저장** → 저장 시트(컬렉션 선택/생성). 상세: [`../06-collections-planning/spec.md`](../06-collections-planning/spec.md) |
| 방문 인증 | `CheckIn` | 상세의 **진입점 버튼** → GPS 인증 플로우. 상세: [`../07-gps-checkin/spec.md`](../07-gps-checkin/spec.md) |
| 사진 추가 | `Post` | 이 스팟에 게시물 업로드. 상세: [`../09-community-feed-upload/spec.md`](../09-community-feed-upload/spec.md) |
| 신고 | `Report`, `ModerationItem` | 사유: 부정확한 위치 / 저작권 / 사유지 침해·민폐 / 부적절 (prd §22) |

**원본 비교 슬라이더**:
- before/after **드래그 슬라이더**. 소스 = **스팟 대표 사진(실촬영) ↔ 내가 찍은 사진** (prd §24).
- 작품 원본 스틸은 소스로 쓰지 않으며 직접 호스팅하지 않는다.

## 인터랙션 흐름
```
스팟 상세 진입(GUEST/USER)
  → 대표 사진·지도(촬영자 위치 핀 + bearing 화살표)·촬영 대상 확인
  → 상세 항목(접근·팁·시간대·렌즈·난이도·혼잡도·주의) 열람
  → [저장] 원탭 → (GUEST면 소프트 게이트) → 저장 시트 → 컬렉션 선택/생성
  → [방문 인증] → (로그인) → GPS 인증 플로우(07)
  → [사진 추가] → (로그인) → 업로드(09) → 갤러리에 반영
  → [원본 비교] 내 사진 존재 시 → before/after 드래그
  → [신고] → 사유 선택 → 통합 검수 큐 접수(11)
```
- 저장/인증/추가/좋아요를 비로그인이 시도 → **소프트 게이트**: 로그인 시트 노출, 성공 후 원래 액션 이어서 수행 (glossary, prd §8).
- 검증 상태 뱃지 탭 → 검증 상태 의미·승격 규칙 안내(요약).
- 관련 작품/회차 탭 → 작품 상세로 이동(성지순례 진행률).

## 엣지 케이스
- **대표 사진 없음**: 필수 필드 미충족 스팟은 정상 노출 대상이 아님 → 데이터 무결성 이슈로 처리(플레이스홀더 최소 표시, 신고 유도). TODO: 미충족 스팟 노출 정책은 검수(11)와 연동.
- **`bearing` 없음**: 방위각 화살표 미표시, 촬영 대상 텍스트만.
- **`subject` 좌표 없음**: 대상 지점 보조 핀 생략, 화살표는 `bearing` 기준으로만 표시.
- **주소 역지오코딩 실패**: 좌표만 표기, 주소 자리 숨김.
- **관련 작품 없음**: 작품 섹션 자체 숨김(일반 여행 스팟).
- **사용자 갤러리 비어 있음**: "첫 사진을 남겨보세요" 빈 상태 + 사진 추가 유도.
- **내가 찍은 사진 없음**: before/after 슬라이더 비활성, 대표 사진 단독 표시 + 인증/업로드 유도.
- **위험 스팟**: 경고 배너·주의사항 최상단 고정, 촬영 매너 고지 (prd §25).
- **삭제·병합된 스팟**: 삭제 안내 / 병합 대상 스팟으로 이동. 연결 게시물의 처리도 함께 안내 (prd §38).
- **재인증 쿨다운·이미 방문**: 방문 인증 버튼 상태(완료/쿨다운 24h)는 07에서 정의, 본 화면은 상태 반영만.
- **오프라인·지도 로드 실패**: 지도 영역 폴백, 상세 텍스트는 계속 열람 가능.

## 인수 조건 (Given/When/Then)
- **Given** 비로그인(`GUEST`) 사용자, **When** 스팟 상세에 진입, **Then** 좌표·지도·촬영 정보 등 **전 항목을 막힘 없이 열람**하고, 저장을 누르면 소프트 게이트로 로그인 후 원래 저장이 이어진다.
- **Given** 스팟의 `verificationStatus`, **When** 상세가 렌더링, **Then** 검증 상태 뱃지가 **색만이 아니라 색+아이콘+라벨**로 병기되어 표시된다 (prd §30).
- **Given** `bearing` 값이 있는 스팟, **When** 지도를 표시, **Then** **촬영자 위치 핀에서 방위각 화살표**가 그려지고, `bearing`이 없으면 화살표가 표시되지 않는다.
- **Given** 사용자가 이 스팟에서 찍은 사진이 있음, **When** 원본 비교를 사용, **Then** **대표 사진 ↔ 내가 찍은 사진**을 before/after 드래그 슬라이더로 비교한다(작품 원본 스틸은 소스가 아니다).
- **Given** 로그인 사용자, **When** 방문 인증 버튼을 탭, **Then** GPS 방문 인증 플로우(07)로 진입한다.
- **Given** 안전 태그가 있는 위험 스팟, **When** 상세를 표시, **Then** 경고 배너와 주의사항이 필수로 노출된다 (prd §25).

## 관련 API / 데이터
- 엔티티: `Spot`(`shooterLat/Lng`, `subject`, `subjectLat/Lng`, `bearing`, `verificationStatus`, `checkinRadiusM`), `Category`, `City`, `Work`/`SpotWork`(`episode`, `sceneNote`), `Post`/`PostImage`(`isVerifiedShot`), `Like`, `CheckIn`, `Collection`/`CollectionItem`, `Report`/`ModerationItem`. 필드 정의: [`../../data-model.md`](../../data-model.md).
- 외부: Google Maps JS API(지도·핀·화살표) + Geocoding(주소 역지오코딩) (prd §34).
- API/서버 액션 시그니처·권한: [`../../api-surface.md`](../../api-surface.md).

## Phase
화면 셸·표시·비교 슬라이더는 **Phase 1**(발견, 비로그인 열람). 단, 액션은 각 기능 Phase에서 활성화된다 (prd §40):
- Phase 1: 상세 표시(사진·지도·촬영 정보·검증 뱃지·주소)·원본 비교 슬라이더.
- Phase 2: 저장(컬렉션) 액션.
- Phase 3: 방문 인증 진입.
- Phase 4: 사진 추가·사용자 갤러리·신고.
