# 스팟 상세 · 원본 비교 슬라이더 — 개발·도메인 규칙 (rules)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 스펙: [`./spec.md`](./spec.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 불변식
- 지도 좌표(`shooterLat`/`shooterLng`)는 **항상 촬영자가 서는 위치**다. 촬영 대상(`subject`) 위치와 절대 혼동하지 않는다 (prd §12, glossary).
- `bearing`은 촬영자 위치에서 **촬영 대상을 향한 방위각(0–360°)**. 화살표 방향은 이 값을 따른다.
- 검증 상태는 **항상 색+아이콘/라벨을 병기**한다. 색만으로 신뢰도를 전달하지 않는다 (prd §30).
- `verificationStatus`는 `OFFICIAL`/`USER_VERIFIED`/`USER_REPORTED`/`ESTIMATED` 네 값만 존재한다 (glossary).
- **열람은 로그인 불필요** — 좌표·상세 포함 전 항목을 `GUEST`가 본다. 저장·인증·사진 추가·신고 **액션만** 로그인(소프트 게이트)이다 (prd §8·§36).
- before/after 비교 소스는 **스팟 대표 사진(실촬영) ↔ 내가 찍은 사진** 뿐이다. **작품 원본 스틸은 소스가 아니며 직접 호스팅하지 않는다** (prd §24).
- 게시물(`Post`)은 스팟에 연결된다. 스팟 비연결 게시물은 없다 (glossary, prd §16).
- 필수/선택 필드는 **prd §13 을 단일 기준**으로 한다. 화면이 임의로 필수/선택을 바꾸지 않는다.

## Do / Don't
- **Do** 촬영자 위치 핀과 방위각 화살표로 "서는 위치+구도"를 시각화한다.
- **Do** 선택 필드가 비면 해당 항목 자리를 **숨긴다**(빈 라벨·"정보 없음" 나열 금지).
- **Do** 위험 스팟(안전 태그)에는 경고 배너와 주의사항을 필수 노출한다 (prd §25).
- **Do** 관련 작품 원본은 **외부 공식 출처 링크**로만 안내한다.
- **Do** 비로그인 액션은 소프트 게이트로 로그인 후 원래 액션을 이어서 수행한다.
- **Don't** 작품 원본 스틸·외부 지오태그 원본 이미지를 재호스팅하지 않는다 (prd §24).
- **Don't** 지도 좌표를 촬영 대상 위치로 표시하지 않는다.
- **Don't** 검증 상태를 색 단독으로 표기하지 않는다.
- **Don't** 원시 GPS 좌표 이력을 이 화면 데이터로 저장·표시하지 않는다(인증 결과만) (prd §23).
- **Don't** data-model에 없는 필드명을 임의로 만들지 않는다.

## 데이터·권한 규칙
- **권한** (prd §36): `GUEST` 열람만 / `USER`·`TRUSTED_USER` 저장·인증·사진 추가·신고 / `MODERATOR`·`ADMIN`은 검수는 어드민에서.
- **주소**는 역지오코딩 파생(자동), 검증 상태·집계(저장·인증·좋아요)도 자동 (prd §13).
- **인기도**는 저장수+인증수+연결 게시물 좋아요의 **파생 지표**이며 원본 저장 컬럼이 아니다 (prd §16).
- **신고 사유** 고정 목록: 부정확한 위치 / 저작권 / 사유지 침해·민폐 / 부적절 (prd §22).
- **방문 인증 진입**만 이 화면 책임. 반경(`checkinRadiusM` 기본 100m)·정확도·쿨다운·mock 감지 판정은 07에서 수행 (prd §17).
- **검증 상태 승격**(USER_REPORTED→USER_VERIFIED 3인 인증 등)은 서버 규칙이며 상세 화면은 결과만 반영 (glossary, prd §18).
- 접근성: 시맨틱 마크업·대체 텍스트·키보드 포커스·대비 준수 (prd §29·§30).

## 정책 연동
- 저작권(prd §24): 원본 스틸 미호스팅, before/after 소스 제한, 외부 출처 링크. → [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/)
- 안전(prd §25): 위험 스팟 경고 배너·주의사항·촬영 매너 고지, 고위험 유형은 등록 차단(등록 측). → [`../12-policies-safety-copyright-privacy/`](../12-policies-safety-copyright-privacy/)
- 개인정보(prd §23): 방문 인증 시에만 위치 사용, 인증 결과만 저장, 사진 EXIF 위치 제거. → [`../07-gps-checkin/`](../07-gps-checkin/) · [`../09-community-feed-upload/`](../09-community-feed-upload/)
- 신고·운영(prd §22): 신고 접수 → 통합 검수 큐. → [`../11-admin-moderation/`](../11-admin-moderation/)
