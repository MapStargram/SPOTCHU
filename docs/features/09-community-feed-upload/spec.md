# 사진 업로드 · 도시 피드 · 좋아요 — 기능 스펙 (spec)

> 상위 원천: [`../../../prd.md`](../../../prd.md) · 규칙: [`./rules.md`](./rules.md) · 용어: [`../../glossary.md`](../../glossary.md)

## 목적
게시물(`Post`) 업로드, 도시 단위 사진 피드, 게시물 좋아요(`Like`)를 정의한다. 피드는 **스팟을 발견하기 위한 수단**이며 인스타그램을 복제하지 않는다(§4). 모든 게시물은 **단일 스팟에 필수로 연결**된다 — 스팟 비연결 게시물은 존재하지 않는다(용어집 `Post`, §16).

## 진입점 / 사용자
- **진입점**
  - 방문 인증 직후 "사진 올리기"([`../07-gps-checkin/`](../07-gps-checkin/)에서 이어짐) → 해당 스팟 **자동 연결**.
  - 탐색 탭 도시 피드([`../03-explore-map-feed/`](../03-explore-map-feed/)의 피드 뷰) 내 업로드 진입.
  - 스팟 상세([`../04-spot-detail/`](../04-spot-detail/)) 사진 갤러리에서 업로드.
  - 프로필 "내 사진"([`../08-gamification-badges/`](../08-gamification-badges/)).
- **사용자/권한**: 열람 = GUEST 포함 전체. 업로드·좋아요 = USER 이상(소프트 게이트). 작품 원본 장면 스틸은 사용자 게시물이 아니라 운영자 영역(§24).
- **노출 surface**: ① 도시 단위 피드(인기/최신 탭) ② 스팟 상세 내 사진 갤러리 ③ 프로필 내 사진.

## 화면 상태
- **도시 피드**: 로딩 / 정상(게시물 목록) / 빈 상태(선택 도시 콘텐츠 없음 → 다른 도시·제보/업로드 유도) / 오류·재시도.
- **피드 탭**: 인기 / 최신 전환.
- **게시물 상세(캐러셀)**: 사진 1~5장 스와이프, 캡션, `isVerifiedShot` 뱃지, 연결 스팟 정보, 좋아요 상태.
- **업로드**: 사진 선택(1~5장) → 편집(캡션 입력 · 스팟 연결) → 게시 → 처리중 → 완료 / 실패.
- **스팟 연결 상태**: 자동 연결됨(인증 직후) / 미연결 → 스팟 검색·지도 선택 필수 / 검색 결과 없음.
- **소프트 게이트**: 비로그인이 업로드·좋아요 시도 → 로그인 요구.
- **좋아요**: 활성/비활성 토글(낙관적 업데이트).
- **소유자 뷰 vs 타인 뷰**: 소유자는 수정/삭제 메뉴, 타인은 신고 메뉴.

## 구성 요소
- **게시물 카드**: 사진 캐러셀(1~5장), `isVerifiedShot` 뱃지, 캡션, 좋아요 수·버튼, 연결 스팟 칩(탭 시 스팟 상세), 오버플로 메뉴(수정/삭제 또는 신고).
- **도시 피드 헤더**: 도시 컨텍스트(전역 상태), 인기/최신 탭.
- **업로드 시트**: 사진 피커(최대 5장), 캡션 입력, 스팟 연결 선택기(자동 연결 배지 또는 검색/지도), 게시 버튼.
- **스팟 사진 갤러리**(스팟 상세 내): 해당 스팟에 연결된 게시물 그리드.
- **프로필 사진 그리드**: 내가 올린 게시물.
- **사진 상세 뷰어**: 캐러셀 + "연결 스팟 위치 보기" + "컬렉션에 저장".

## 인터랙션 흐름
1. **인증 후 업로드**: 방문 인증 완료 → "사진 올리기" → 스팟 자동 연결 → 사진 1~5장 선택 → 캡션 → 게시 → `isVerifiedShot=true`로 즉시 노출.
2. **일반 업로드**: 업로드 진입 → 사진 선택 → **스팟 검색/지도에서 연결(필수)** → 캡션 → 게시 → 즉시 노출(사후 신고 기반).
3. **좋아요**: 게시물 좋아요 버튼 → 토글(사용자당 게시물당 1회) → 낙관적 반영 → 스팟 인기도 파생 지표에 합산(§16).
4. **사진 클릭**: 사진 상세 → 연결 스팟 위치 확인(스팟 상세/지도 이동) → 컬렉션에 저장([`../06-collections-planning/`](../06-collections-planning/)).
5. **수정/삭제**: 작성자 본인 → 오버플로 메뉴 → 캡션/사진 수정 또는 삭제.
6. **신고**: 타 사용자 게시물 → 신고 → 통합 검수 큐(운영, [`../11-admin-moderation/`](../11-admin-moderation/)).

## 엣지 케이스
- 비로그인 업로드·좋아요 시도 → 소프트 게이트(로그인 요구).
- 일반 업로드에서 스팟 미연결 → 게시 차단(필수 연결).
- 사진 0장 또는 6장 이상 선택 → 검증 실패 안내(1~5장 강제).
- 업로드 실패·대용량·약전계(§38) → 재시도 안내.
- 삭제된 스팟에 연결된 게시물(§38) → 처리 정책 미정(rules TODO).
- EXIF 위치 정보 포함 사진 → 서버 저장 전 제거(§23).
- 좋아요 연타/중복 요청 → 서버 멱등 처리(중복 카운트 없음).
- 선택 도시 피드 빈 상태 → 빈 상태 + 다른 도시/제보 유도(00-IA와 동일 패턴).
- 인증 이력이 없는 스팟에 일반 업로드 → `isVerifiedShot` 부여 여부 미정(rules TODO).

## 인수 조건 (Given/When/Then)
- **Given** 방문 인증을 막 완료한 USER, **When** "사진 올리기"로 진입, **Then** 해당 스팟이 자동 연결된 상태로 업로드가 시작된다.
- **Given** 일반 업로드 중 스팟 미연결, **When** 게시를 시도, **Then** 게시가 차단되고 스팟 검색/지도 선택을 요구한다.
- **Given** 사진 6장을 선택, **When** 업로드, **Then** 1~5장 제한 안내로 게시가 차단된다.
- **Given** 로그인한 USER가 타인 게시물을 열람, **When** 좋아요를 누름, **Then** 좋아요가 토글되고 해당 스팟 인기도 파생 지표에 합산된다.
- **Given** 비로그인 GUEST, **When** 좋아요 또는 업로드를 시도, **Then** 소프트 게이트(로그인 요구)가 노출된다.
- **Given** 게시물 사진을 클릭, **When** 사진 상세를 열람, **Then** 연결 스팟 위치 확인과 컬렉션 저장이 가능하다.

## 관련 API / 데이터
- 엔티티: `Post`(작성자, 연결 `Spot`(필수), 사진 1~5장, 캡션, `isVerifiedShot`), `PostImage`, `Like`(게시물 전용). 연동: `CheckIn`(`isVerifiedShot` 근거), `Collection`(사진 → 저장), `Report`·`ModerationItem`(신고).
- **스팟 인기도** = 저장수 + 인증수 + 연결 게시물 좋아요 합산 파생 지표(§16). 09는 좋아요 합산 기여만 담당.
- 상세: [`../../data-model.md`](../../data-model.md) · [`../../api-surface.md`](../../api-surface.md).
