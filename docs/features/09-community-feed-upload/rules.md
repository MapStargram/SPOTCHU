# 사진 업로드 · 도시 피드 · 좋아요 — 규칙 (rules)

## 불변식 (Invariants)
- 모든 `Post`는 **정확히 하나의 `Spot`에 연결**된다. 스팟 비연결 게시물은 존재하지 않는다(용어집, §16).
- 게시물 사진은 **1~5장**(캐러셀).
- `Like`는 **게시물에만** 부여된다(스팟·컬렉션·작품에는 좋아요 없음, §16).
- 사용자 실촬영 게시물은 **즉시 노출**되며 **사후 신고 기반**으로 운영된다(§22·§24).
- 업로드 사진의 **EXIF 위치 정보는 서버 저장 전 제거**한다(§23).
- 서비스는 **작품 원본 스틸을 직접 호스팅하지 않는다**(§24). 게시물은 사용자 실촬영만 받는다.
- 스팟 인기도는 저장수 + 인증수 + 연결 게시물 좋아요의 **파생 지표**이며, 09는 좋아요 합산 기여만 담당(원천 계산은 스팟 도메인).

## Do / Don't
- ✅ 방문 인증 직후 업로드는 해당 스팟을 자동 연결한다.
- ✅ 일반 업로드는 스팟 검색/지도에서 연결을 강제한다.
- ✅ 좋아요는 사용자당 게시물당 1회(토글), 서버에서 멱등 처리한다.
- ✅ 게시물 수정·삭제는 **작성자 본인만**. 타인은 신고만 가능하다.
- ❌ 스팟 미연결 게시물을 생성하지 않는다.
- ❌ 게시물 좋아요를 스팟·컬렉션·작품으로 확장하지 않는다.
- ❌ 작품 원본 스틸을 사용자 업로드로 받거나 직접 호스팅하지 않는다.
- ❌ 댓글·팔로우를 추가하지 않는다(MVP 제외, §5·§27).

## 데이터·권한 규칙
- **GUEST**: 피드·갤러리·게시물 열람만. 업로드·좋아요·수정·삭제·신고 불가(소프트 게이트).
- **USER**: 업로드 · 좋아요 · 본인 게시물 수정/삭제 · 신고.
- **작품 원본 장면 스틸**: 운영자 영역. 직접 호스팅 금지, 외부 공식 출처 링크로 안내(§24).
- `isVerifiedShot`: 방문 인증 흐름에서 업로드된 게시물에 부여(GPS 인증 사진 뱃지, §16).
- 사진은 EXIF 위치 제거 후 저장하며, 원시 좌표 이력은 보관하지 않는다(§23).
- 신고는 통합 검수 큐(`ModerationQueue`)로 유입된다(§21·§22).
