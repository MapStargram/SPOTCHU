# SPOTCHU 용어집 (Glossary)

> 모든 문서·코드·커밋에서 아래 용어를 일관되게 사용한다. 새 용어가 생기면 여기에 먼저 추가한다.

| 용어 | 코드 식별자 | 정의 |
|---|---|---|
| 스팟 | `Spot` | 특정 사진을 찍기 위해 **촬영자가 서야 하는 정확한 위치와 구도**. 제품의 기본 데이터 단위. "장소(도쿄타워)"가 아니라 "그 장소를 찍는 하나의 지점·구도". |
| 촬영자 위치 | `shooterLat`, `shooterLng` | 스팟의 좌표. **항상 촬영자가 서는 지점**을 의미한다 (촬영 대상 위치가 아님). |
| 촬영 대상 | `subject`, `subjectLat/Lng` | 카메라가 향하는 피사체(예: 도쿄타워). 좌표는 선택. |
| 카메라 방향 | `bearing` | 촬영자 위치에서 촬영 대상을 향한 방위각(0–360°). 지도에서 대상 지점을 탭하면 자동 계산. |
| 검증 상태 | `verificationStatus` | 스팟 신뢰도. `OFFICIAL`(공식 인증) / `USER_VERIFIED`(사용자 검증) / `USER_REPORTED`(사용자 제보) / `ESTIMATED`(위치 추정). |
| 방문 인증 | `CheckIn` | 스팟 허용 반경 내에서 실시간 GPS로 방문을 확인하는 행위. GPS만으로 완료 가능, 사진은 선택. |
| 허용 반경 | `checkinRadiusM` | 방문 인증이 가능한 반경(m). 기본 100m, 스팟별 오버라이드 가능. |
| 컬렉션 | `Collection` | 사용자가 스팟을 저장·정리하는 묶음(여행 계획 단위). 기본함 "저장됨" + 사용자 생성. |
| 게시물 | `Post` | 스팟에 연결된 사용자 사진(최대 5장 캐러셀 + 캡션). 스팟 비연결 게시물은 없다. |
| 작품 | `Work` | 애니·영화·드라마 등 콘텐츠. 스팟과 다대다로 연결(회차 정보 포함). 성지순례 진행률의 기준. |
| 배지 | `Badge` | 수집·게임화 보상. 도시/성지순례 완주/최초 제보자 등. |
| 스팟 후보 리드 | `SpotLead` | 외부 지오태그 콘텐츠에서 수집한 좌표·출처 메타데이터. 운영자 검증 전 상태. 원본 이미지는 저장하지 않는다. |
| 소프트 게이트 | — | 비로그인 사용자가 액션(저장·인증·업로드·좋아요)을 시도하는 순간에만 로그인을 요구하는 방식. 열람은 막지 않는다. |
| 통합 검수 큐 | `ModerationQueue` | 신규 제보·신고·공식 승격 후보·작품 스틸 요청을 한곳에서 처리하는 운영자 작업 큐. |

## 검증 상태 승격 규칙 (요약)
- `USER_REPORTED` → `USER_VERIFIED`: 서로 다른 사용자 **3명 이상**의 GPS 방문 인증 누적 시 **자동** 승격.
- `USER_VERIFIED`/인기 스팟 → `OFFICIAL`: 좋아요·인증 수가 높으면 **운영자 우선 검수 큐**에 노출, 운영자 판단으로 승격(자동 아님 — 위치 정확성 원칙 보호).
- `ESTIMATED`: 작품 배경으로 추정되나 미확인. 지도·상세에서 명확히 구분 표기.
